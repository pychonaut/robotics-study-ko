# 종이 팔로 배우는 로봇공학 입문

스탠퍼드 CS223A 「로봇공학 입문」(Oussama Khatib, 2008)을 혼자 공부하려고 한국어로 새로 쓴 교재입니다. 그림과 슬라이더로 직접 움직여 보는 그림으로 설명합니다.

- 웹으로 보기: https://pychonaut.github.io/robotics-study-ko/
- 원고: `src/*.md` → `build.py` → `docs/*.html` (`uv run --no-project --with markdown python build.py`)
- 그림: `docs/assets/figures.js`

강의 자료는 [Stanford Engineering Everywhere](https://see.stanford.edu/Course/CS223A)가 Creative Commons Attribution 3.0으로 공개했습니다. 이 교재는 스탠퍼드의 공식 자료가 아닙니다.
