16장. 닿으면서 움직이기: 힘 제어, 사람 곁의 로봇, 온몸 제어

손끝이 무언가에 닿으면 위치만 지키는 제어는 위험하다. 이 장은 손끝을 용수철처럼 부드럽게 만들고, 접촉 힘을 재서 되먹임하고, 방향마다 움직임과 힘을 나눠 맡기는 법을 배운 뒤 사람 곁의 안전한 팔과 온몸 제어로 마무리한다. 강의 16강(70분)에 해당한다.

16.1 15장에서 이어서: 닿으면 무엇이 달라지나

15장에서는 손끝에서 바로 제어했다. 손끝이 낼 가속도 F′를 정하고, 작업 공간 질량 행렬 Λ와 속도 몫 μ, 중력 몫 p를 채워 손끝 힘 F를 만들었다. 이 F를 τ = JᵀF로 관절 토크로 바꾸면, 모델 추정값(모자 ^)이 맞을 때 손끝은 질량 1인 물체처럼 ẍ = F′로 움직인다.

F′는 13장의 PD 제어와 같은 모양이다. 손끝이 목표 xd에서 벗어난 만큼 되돌리고, 빠른 만큼 브레이크를 건다.

위치 제어는 손끝에 용수철을 단 것이다

멈춰 있는 손끝을 손가락으로 Δx만큼 밀어 보자. 추정이 맞으면 속도 몫과 중력 몫은 서로 지워진다. 남는 것은 F = −Λ kp Δx, 곧 밀린 만큼 되미는 용수철이다.

용수철이 얼마나 단단한지를 강성(stiffness)이라 한다. 위치 제어의 강성은 K = Λ kp다. 강의는 이것을 "닫힌 고리 강성"이라 부른다.

예를 들어 손끝이 느끼는 질량이 Λ = 0.5 kg이고 kp = 400 /s²이면 K = 200 N/m = 2 N/cm다. 손끝을 1 cm 밀면 2 N으로 되민다.

목표가 벽 속에 있으면

위치 제어는 "어디에 있어야 하는지"만 안다. 목표를 정할 때 벽의 자리를 조금만 틀려도, 제어기는 벽 속의 목표를 향해 계속 민다. 손끝이 벽에 막히면 힘은 F = K × (막힌 거리)가 된다.

정확히 따라가려고 강성을 키운 팔일수록 위험하다. K = 20 N/cm인 팔은 2.5 cm 오차로 50 N을 낸다. 컵은 깨지고, 강의 첫 영상의 유리창도 깨진다.

잠깐, 생각해 보기. 14장에서 본 적분 항(I)이 있는 위치 제어기로 벽 속의 목표를 누르면 어떻게 될까?

손끝이 벽에 막혀 오차가 사라지지 않는다. 적분 값이 계속 쌓이니 누르는 힘도 시간이 갈수록 커진다. 결국 벽이든 팔이든 무언가가 부서진다.

16.2 용수철처럼 굴기: 강성과 컴플라이언스

닿을 일이 있으면 일부러 무르게 만든다. 밀면 잘 밀리는 정도를 컴플라이언스(compliance)라 하고, 강성의 거꾸로(1/k)다.

방향마다 강성을 따로 고른다

작업 공간 제어는 x, y, z 방향마다 kp를 따로 둘 수 있다. 강의는 z 방향의 kpz만 바꿔 보인다.

  • kpz가 크다: z로 밀어도 꿈쩍 않는다.
  • kpz를 줄인다: 밀면 밀리고, 놓으면 돌아온다.
  • kpz = 0: 용수철이 끊긴다. 밀면 밀린 자리에 머문다. 감쇠 −kvż만 남아 끈적하게 밀린다.

x, y는 단단하게 두고 z만 무르게 하면, 손끝은 옆으로 정확히 가면서 위아래로는 밀리는 대로 따라간다. 표면을 따라가는 일의 첫걸음이다.

벽 누르기: 용수철 두 개

종이 팔로 벽을 눌러 보자. 목표를 벽 속 d에 두면 용수철이 두 개 생긴다. 제어가 만든 용수철(kp)과 벽 자체의 용수철(kw)이다.

손끝이 벽을 δ만큼 누른 곳에서 두 용수철의 힘이 같아진다. 제어 용수철은 d − δ만큼, 벽은 δ만큼 늘어난다.

해 볼 것 세 가지:

  1. 처음 값(kp = 2 N/cm, 벽 50 N/cm, d = 1 cm): F = 1.92 N, δ = 0.038 cm다. 벽이 훨씬 단단해서 d의 거의 다를 제어 용수철이 맡는다.
  2. kp를 50으로 올린다: F = 25 N, δ = 0.5 cm다. 두 강성이 같으면 d를 반씩 나눈다.
  3. kp = 50에서 벽 강성을 1(스펀지)로 내린다: F = 0.98 N이다. 이번에는 벽이 거의 다 들어간다.

무른 쪽이 힘을 정한다. 벽이 단단해도 제어를 무르게 하면 힘이 작다. 단단한 것끼리 만나면 작은 오차도 큰 힘이 된다.

수학 더하기: 이어 붙인 용수철. 용수철 두 개를 이어 붙이면 같은 힘 F가 둘 다에 걸린다. 늘어난 길이는 각각 F/k₁, F/k₂이고 합이 전체 길이 d다. 그래서 d = F(1/k₁ + 1/k₂)이고, 합친 강성은 1/(1/k₁ + 1/k₂)라서 컴플라이언스(1/k)끼리 더해진다.

관절에서 본 강성: JᵀKJ

손끝의 강성 K를 관절에서 느끼면 얼마일까? 관절을 δθ만큼 돌리면 손끝은 δx = J δθ만큼 움직인다. 용수철은 −Kδx로 되밀고, 이 힘은 Jᵀ를 거쳐 관절 토크가 된다.

종이 팔 θ = (30°, 60°)에서 J = [[−13, −8], [8.66, 0]] cm다(6장). 손끝 강성이 두 방향 모두 2 N/cm라면 이렇다.

어깨만 0.01 rad 돌리면 어깨는 4.88 N·cm, 팔꿈치는 2.08 N·cm의 되돌리는 토크를 느낀다. 비대각 칸은 "한 관절을 돌리면 다른 관절도 버틴다"는 뜻이다. 강의는 이 식으로 관절 공간의 강성을 미리 따져 볼 수 있다고 말한다.

16.3 힘 제어: 재고, 되먹임하고, 감쇠한다

컴플라이언스는 힘을 "작게" 할 뿐, "원하는 크기"로 맞추지는 못한다. 유리창을 닦으려면 정해진 힘으로 눌러야 한다. 접촉 힘을 목표 Fd에 맞추는 것이 힘 제어(force control)다.

그냥 명령하면 안 되는 이유: 마찰

손끝 힘을 F = Fd로 명령하면 그대로 누를까? 모터와 기어에는 마찰이 있다.

  • 정지 마찰: 움직이기 시작하려면 넘어야 하는 문턱이다. 명령이 이보다 작으면 꿈쩍 않는다.
  • 쿨롱 마찰: 움직이는 동안 늘 같은 크기로 막는다.
  • 점성 마찰: 빠를수록 커진다.

강의 예처럼 1 N·m를 명령해도 마찰이 그보다 크면 바깥에 나오는 힘은 0이다. 마찰은 정확히 모르고 때마다 바뀌어서, 계산으로 미리 빼 주기도 어렵다. 그래서 나온 힘을 재야 한다.

힘 센서는 아주 단단한 용수철

손목에 다는 힘 센서 속에는 아주 단단한 탄성체가 있다. 힘이 걸리면 아주 조금 휘고, 그 휜 양 δs를 재서 Fs = ksδs로 힘을 낸다. 강성이 10⁷ N/m라면 10 N에 1 µm만 휜다.

16.2절의 F = kΔx가 다시 나왔다. 힘을 잰다는 것은 아주 작은 길이를 재는 것이다.

되먹임 제어

잰 힘 Fs로 되먹임하는 가장 단순한 제어는 이렇다.

  • Fd: 앞먹임(feedforward)이다. 마찰이 없다면 이것만으로 된다.
  • kf(Fd − Fs): 잰 힘이 모자란 만큼 더 민다. 힘 이득 kf는 단위가 없다.
  • −kvẋ: 감쇠다. 손끝이 빨리 움직이면 브레이크를 건다.

마찰 Ffr가 있어도 오차가 줄어든다. 손끝이 멈추면 모터 힘 F와 접촉 힘 Fs의 차이를 마찰이 받는다. 그 차이는 (1 + kf)(Fd − Fs)이고 Ffr를 넘지 못하니, 남는 오차는 이만큼이다.

마찰이 0.5 N이면 kf = 0일 때 0.5 N, kf = 4일 때 0.1 N까지 틀릴 수 있다. 14장의 적분 항을 더하면 오차가 0으로 간다. 14강에서 교수가 "적분은 힘 제어에서 아주 좋다"고 한 것이 이것이다.

닿은 뒤의 동역학

손끝을 질량 m인 물체 하나로, 벽을 강성 ke인 용수철로 본다. 벽 속으로 들어간 깊이를 x라 하면 Fs = kex다. 마찰은 잠시 빼고, 운동 방정식에 제어를 넣어 보자.

13장의 질량-용수철-감쇠기와 같은 식이다. 용수철 자리에 (1 + kf)ke가 들어갔을 뿐이다. 그래서 고유 진동수와 감쇠비가 이렇다.

x = Fs/ke를 넣으면 같은 식을 힘으로 쓸 수 있다. 강의가 말한 "힘으로 다시 쓰기"다. 접촉 힘 자체가 질량-용수철처럼 흔들린다.

읽을 것 두 가지:

  1. 벽이 단단할수록(ke가 클수록), 힘 이득 kf가 클수록 빨리 흔들린다.
  2. 같은 감쇠 kv라도 그만큼 ζ가 작아진다. 단단한 것을 세게 되먹임할수록 감쇠가 더 필요하다.

예를 들어 m = 0.5 kg, ke = 50 N/cm(5000 N/m), kf = 1이면 ω = 141 rad/s(22.5 Hz)다. ζ = 0.7을 원하면 kv = 99 N·s/m가 필요하다.

해 볼 것 네 가지:

  1. 마찰 0, 감쇠 0: 힘이 0과 4 N 사이를 끝없이 오간다. ζ = 0이다.
  2. 그대로 감쇠만 100으로 올린다: 0.05초 안에 2 N에 자리 잡는다(ζ = 0.71).
  3. 힘 이득 0, 마찰 0.5 N, 감쇠 100: 1.5 N에서 멈춘다. 마찰만큼 모자란다. 힘 이득을 4로 올리면 오차 폭이 ±0.1 N으로 준다.
  4. 힘 이득 0, 마찰 2.5 N: 아예 움직이지 않아 0 N이다. 명령 2 N이 마찰을 못 넘는다. 강의의 "1 N·m를 줘도 0"이다.

알아 두기. 이 그림의 손끝은 센서 값을 늦음 없이 받는다. 실제로는 계산 주기와 걸러 내기 때문에 값이 조금 늦게 오고, 팔도 휜다. 그래서 단단한 벽에서 힘 이득을 크게 올리면 흔들림이 자라 불안정해진다.

닿기 전도 조심해야 한다. 빈 공간에서는 Fs = 0이라 손끝이 (1 + kf)Fd로 가속하며 달려든다. 다가가는 동안 감쇠로 속도를 묶어 두어야 세게 부딪히지 않는다.

16.4 방향 나누기: 움직일 방향과 누를 방향

유리창 닦기는 두 가지를 한꺼번에 한다. 창을 따라 걸레를 옮기고(움직임), 창에 수직으로 눌러 준다(힘). 그런데 한 방향에서 위치와 힘을 둘 다 마음대로 고를 수는 없다. 벽 속으로는 움직일 수 없고, 빈 공중으로는 힘을 낼 수 없다.

닿으면 자유도가 힘 쪽으로 간다

손에 쥔 물체가 탁자에 닿는 모양에 따라 잃는 자유도가 다르다. 강의의 세 예를 보자. 탁자 면이 x·y, 위쪽이 z다.

  • 공: 점으로 닿는다. z로만 못 움직인다. 미끄러지기 2와 돌기 3이 남아 움직임 5, 힘 1이다.
  • 눕힌 원기둥(축이 x 방향): 선으로 닿는다. z 이동과 y축 돌기(한쪽 끝 들기)를 잃는다. x축으로 구르기와 z축으로 돌기는 남아 움직임 4, 힘 2다.
  • 상자: 면으로 닿는다. z 이동, x축 돌기, y축 돌기를 잃는다. 움직임 3, 힘 3이다.

잃은 자유도는 사라진 것이 아니다. 그 방향으로는 10 N이든 20 N이든 누르는 힘을, 그 축으로는 모멘트를 고를 수 있다. 언제나 움직임 자유도 + 힘 자유도 = 6이다.

잠깐, 생각해 보기. 펜으로 칠판에 글씨를 쓴다. 펜 끝은 판에 점으로 닿는다. 움직임과 힘의 자유도는 각각 몇인가?

공과 같다. 판을 따라 두 방향으로 미끄러지고 펜을 세 축으로 돌릴 수 있어 움직임 5다. 힘은 판에 수직으로 누르는 1이다.

선택 행렬 Ω

방향을 나누려면 판에 좌표계 {B}를 붙인다. 평면에서 보면 xB는 판을 따라, yB는 판에 수직으로 벽 속을 향한다.

{B}에서는 고르기가 쉽다. 움직일 방향은 1, 누를 방향은 0으로 적은 대각 행렬 Σ다.

받침 좌표계 {0}에서 쓰려면 2장의 회전행렬로 감싼다. 받침의 숫자를 {B}로 바꾸고(Rᵀ), 고르고(Σ), 다시 받침으로 돌린다(R). 이것이 선택 행렬(selection matrix) Ω다.

판이 x₀에서 α만큼 기울었다면 c = cos α, s = sin α로 이렇다.

Ω는 판을 따르는 몫만 남기고, Ω̃는 판에 수직인 몫만 남긴다. 둘을 더하면 단위행렬이라 빠지는 방향이 없다. 3차원에서는 6 × 6이 되고, 힘뿐 아니라 모멘트의 방향도 나눈다.

수학 더하기: 투영 행렬. t = (c, s)를 판 방향의 단위 벡터라 하면 Ω = t tᵀ다. 벡터 v에 곱하면 Ω v = t (t·v), 곧 v가 판 위에 드리우는 그림자다(2장의 내적). 그림자의 그림자는 그대로라 ΩΩ = Ω이고, 판 위의 그림자를 수직 방향으로 다시 비추면 0이라 ΩΩ̃ = 0이다.

해 볼 것 세 가지:

  1. α = 0°: Ω = [[1, 0], [0, 0]]이다. F′의 y 몫 0.6 N이 지워져 ΩF′ = (1, 0) N이다.
  2. α = 30°: Ω = [[0.75, 0.43], [0.43, 0.25]]이다. F′가 거의 판 방향이라 대부분 남아 ΩF′ = (1.01, 0.58) N이다.
  3. 누르는 힘을 0으로: 펜은 판을 따라 움직이기만 하고 누르지 않는다. 글씨가 써지지 않는다.

16.5 움직임과 힘을 한 식으로

이제 두 제어를 합친다. 움직임 제어는 Ω 방향에서만, 힘 제어는 Ω̃ 방향에서만 일한다. 둘 다 손끝에서 쓴 힘이라 더하기만 하면 된다.

Fmotion은 15장의 움직임 제어를 Ω로 거른 것이고, Fforce는 16.3절의 힘 제어를 Ω̃로 거른 것이다. 강의는 이것을 움직임과 힘의 통합 제어(unified motion and force control)라 부른다. 강의의 식은 힘 쪽 되먹임에도 Λ̂를 곱해 두 쪽이 서로 끌려가지 않게 하는데, 여기서는 뜻만 보려고 뺐다.

16.7 큰 모터와 작은 모터: 매크로-미니 구동

팔을 가볍게 하기 어려운 까닭은 모터가 모터를 업고 다니기 때문이다. 링크를 돌리려면 모터가 있어야 하고, 그 모터를 앞 관절의 모터가 들어야 한다. 그래서 무게가 받침 쪽으로 쌓인다.

모터를 고를 때는 두 가지를 본다. 중력을 오래 버틸 연속 토크(continuous torque)와, 빨리 가속할 때 잠깐 내는 큰 토크다. 큰 토크를 계속 내면 모터가 탄다.

큰 토크는 느릴 때만 필요하다

강의의 핵심 관찰은 이것이다. 큰 토크는 중력 버티기나 느린 움직임처럼 낮은 주파수에서 필요하다. 빠르게 바로잡는 높은 주파수 쪽은 작은 토크면 된다.

그러니 관절 하나에 모터 하나일 필요가 없다. 사람도 관절마다 크고 작은 여러 근육을 쓴다.

  • 큰 모터(매크로): 받침에 둔다. 팔이 그 무게를 들지 않는다. 탄성을 거쳐 관절에 이어져, 부딪힐 때 그 관성이 용수철 뒤에 숨는다.
  • 작은 모터(미니): 관절에 바로 붙는다. 작고 가벼워서 부딪혀도 위험이 적고, 빠르게 반응한다.

스탠퍼드는 이것을 분산 매크로-미니 구동(DM², distributed macro-mini actuation)이라 부른다. 강의에 따르면 PUMA만 한 팔의 실효 관성을 10분의 1(35 → 3.5 kg)로 줄일 수 있다. 16.6절의 계산으로는 필요한 쿠션이 10분의 1, 최대 힘이 약 3분의 1(1/√10)이 된다.

용수철은 선물을 하나 더 준다. 용수철이 늘어난 길이를 재면 F = kΔx로 전해지는 토크를 안다. 16.3절의 힘 센서와 같은 생각이다.

16.8 과제와 자세: 남는 자유도 쓰기

1990년대 스탠퍼드의 Romeo와 Juliet은 바퀴 달린 받침에 팔을 얹은 로봇이다. "옮기고, 멈추고, 집고, 다시 옮기기"가 아니라 움직이면서 다룬다. 물건을 든 채 받침이 장애물을 비켜 가도 손은 흔들리지 않는다.

2장 2.3절의 3관절 팔(8 cm, 7 cm, 5 cm)이 손끝 위치만 지킨다고 하자. 관절 3개에 과제 2개라 여유가 1이다. 손끝을 고정한 채 팔 모양만 바꿀 수 있다.

주황 화살표를 따라 움직여도 손끝 속도는 J θ̇ = 0이다. 손끝을 움직이지 않는 관절 속도들의 모임을 J의 영공간(null space)이라 한다.

8장 그림 8-3의 자세 θ = (0°, 90°, −90°)로 숫자를 확인해 보자. 손끝 위치만의 J는 2 × 3이고, θ̇ = (1, −1, −1.6) rad/s를 곱하면 0이 나온다.

수학 더하기: 영공간 찾기. 행렬 J에 곱해서 0이 나오는 벡터들을 J의 영공간이라 한다. J가 2 × 3이면 보통 한 방향이다. 그 벡터는 J의 두 행에 모두 수직이라, 두 행을 3차원 벡터로 보고 외적하면 바로 나온다(6장). (−7, −7, 0) × (13, 5, 5) = (−35, 35, 56)이고, −35로 나누면 (1, −1, −1.6)이다.

토크로 쓰면: 영공간 거르개

토크로 제어할 때도 같은 생각을 쓴다. 과제 힘은 JᵀFtask로 넣고, 자세를 바꾸려는 토크 τposture는 거르개 Nᵀ를 거쳐 더한다.

Nᵀ는 τposture에서 손끝을 가속하는 몫을 빼고 영공간 쪽 몫만 남긴다. 그래서 자세가 움직여도 자세 토크 때문에 생기는 손끝 가속도는 0이다. N을 만드는 법은 다음 학기 여유자유도 수업에서 다룬다고 강의는 말한다.

16.9 여러 곳이 닿는 몸: 전신 제어

휴머노이드는 팔 하나보다 훨씬 어렵다. 관절이 수십 개이고, 몸이 가지처럼 갈라지며, 두 발과 손이 동시에 닿는다. 한쪽을 당기면 다른 모든 곳이 영향을 받는다.

2장 2.1절에서 본 대로 몸통은 바닥에 붙어 있지 않아 자유도 6이 더 있고, 그 6개에는 모터가 없다. 강의 말대로 휴머노이드는 늘 균형을 잡느라 바쁘다. 밀면 넘어지고, 움직이려면 닿은 곳의 힘을 잘 나눠야 한다.

역기구학 대신 끌어당기기

관절이 이렇게 많으면 끝 자세를 미리 역기구학으로 정하는 것은 무모하다. 관절 한계, 장애물, 균형이 움직이는 동안 계속 바뀌기 때문이다.

그래서 1장 1.5절의 길을 간다. 손을 목표로 끌어당기면 자세는 저절로 나온다.

여러 점을 하나로 묶는다

오른손, 왼손, 머리처럼 제어할 점이 여럿이면 어떻게 하나? 강의의 답은 "한 걸음 물러서라"다. 점들의 좌표를 모두 이어 붙여 큰 과제 벡터 하나로 보면, 높은 차원에서 그것은 다시 점 하나다.

그러면 자코비안도 Λ도 하나씩 나온다. Λ의 대각 블록은 점마다의 질량 성질이고, 비대각 블록은 점끼리 끌려가는 정도다. 15장의 식을 그대로 쓴다.

지켜야 할 것부터: 제약과 우선순위

관절 한계, 자기 몸과 부딪히지 않기, 장애물 같은 제약(constraint)은 가장 먼저 지켜야 한다. 제약의 자코비안을 알면 그 영공간도 안다. 과제와 자세를 모두 그 영공간 안에 넣으면, 무엇을 하든 제약을 깨지 않는다.

여러 곳이 닿을 때

닿는 곳의 수직 방향이 제약이다. 그 자코비안과 영공간을 구해, 움직임은 영공간 안에서 하고 닿는 곳의 힘은 따로 조절한다. 강의는 이것이 16.4절의 Ω와 Ω̃를 "여러 곳이 닿는 공간"으로 넓힌 것이라 말한다.

그러면 몸무게를 여러 닿는 곳에 나눠 싣고, 균형을 지키며, 손으로 일을 할 수 있다. 강의 당시 이 구조가 ASIMO 같은 휴머노이드에 들어가고 있었다.

그 위에 쌓는 것

이 수업에서 배운 것은 가장 아래층, 곧 움직임을 실제로 해내는 제어다. 그 위에 장애물을 보고 비키기, 사람에게서 배운 솜씨 같은 행동을 쌓는다. 바탕이 튼튼해야 위로 올라갈 수 있다.

강의는 다른 연구도 짧게 보여 준다. 미리 짠 길을 실시간으로 휘어 장애물을 피하는 탄성 계획, 닿는 점의 실효 질량만으로 계산하는 빠른 충돌 시뮬레이션이다. 강의 내용은 "언젠가 ASIMO도 졸업시키고 싶다"는 말로 끝난다.

import numpy as np

np.set_printoptions(precision=3, suppress=True)
D = np.pi / 180

def jac(t1, t2):
    """종이 팔(10 cm, 8 cm)의 자코비안 (cm/rad)."""
    s1, c1, s12, c12 = np.sin(t1), np.cos(t1), np.sin(t1 + t2), np.cos(t1 + t2)
    return np.array([[-10 * s1 - 8 * s12, -8 * s12], [10 * c1 + 8 * c12, 8 * c12]])

def wall_press(kp, kw, d):
    """제어 용수철 kp와 벽 kw가 목표 깊이 d를 나눠 가질 때: (힘, 벽 눌림)."""
    F = kp * kw / (kp + kw) * d
    return round(F, 3), round(F / kw, 3)

def omega(alpha_deg):
    """판이 alpha만큼 기울었을 때의 선택 행렬 Ω와 Ω̃."""
    c, s = np.cos(alpha_deg * D), np.sin(alpha_deg * D)
    O = np.array([[c * c, c * s], [c * s, s * s]])
    return O, np.eye(2) - O

def force_sim(kf, kv, fr, Fd=2.0, m=0.5, ke=5000.0, T=0.3, dt=1e-4):
    """1자유도 힘 제어: 벽에 막 닿은 손끝이 0초에 목표 Fd를 받는다. (최대 힘, 끝 힘)."""
    x = v = 0.0
    hist = []
    for _ in range(round(T / dt) + 1):
        Fs = ke * x if x > 0 else 0.0
        hist.append(Fs)
        Fn = Fd + kf * (Fd - Fs) - kv * v - Fs        # 모터 힘 - 접촉 힘
        if v == 0.0:
            a = 0.0 if abs(Fn) <= fr else (Fn - fr * np.sign(Fn)) / m
        else:
            a = (Fn - fr * np.sign(v)) / m
        vn = v + a * dt
        if v != 0.0 and np.sign(vn) != np.sign(v):    # 마찰은 방향을 뒤집지 못한다
            vn = 0.0
        v = vn
        x += v * dt
    return round(float(max(hist)), 3), round(float(hist[-1]), 3)
