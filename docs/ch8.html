8장. 속도는 J로, 힘은 Jᵀ로: 특이점, 손끝 속도 제어, 정적 힘

자코비안은 관절 속도를 손끝 속도로 옮기고, 손끝의 힘을 관절 토크로 거꾸로 옮긴다. 이 장은 실제 팔에서 특이점을 확인하고, 손끝 속도를 명령해 팔을 움직이는 법과 손끝 힘을 버티는 토크를 구하는 법을 배운다. 강의 8강(75분)에 해당한다.

8.1 실물 스탠퍼드 팔: 손목 특이점

강의는 자동차가 스스로 평행 주차하는 영상(INRIA, 1999)과 중간고사 안내로 시작한다. 중간고사 범위는 이 강의까지, 곧 자코비안까지다. 이어서 교수가 1970년대 초에 만든 실물 스탠퍼드 Scheinman 팔을 보여 준다.

5~7장에서 그림과 식으로만 본 팔이다. 교수는 관절을 하나씩 짚는다.

  • 관절 1, 2: 관절 1은 몸통 전체를 세로축으로 돌리고, 관절 2는 붐을 위아래로 기울인다. 제어기에 연결하지 않아서 브레이크로 붐을 수평으로 잡아 두었다.
  • 관절 3: 직동 관절이다. 방향을 정한 뒤 붐을 곧게 뻗어 빨리 닿을 수 있다. 대신 양쪽 끝에 멈춤 장치가 있어 늘이고 줄이는 길이에 한계가 있다.
  • 관절 4, 5, 6: 손목이다. 세 축이 손목점 W에서 만난다(5장).

θ₅ = 0이면 축 4와 축 6이 한 줄이 된다

교수가 관절 5를 0으로 돌리자 학생들이 바로 "특이점"이라고 답한다. θ₅ = 0이면 관절 4의 축 z₄와 관절 6의 축 z₆이 한 줄에 놓인다(7.10절). 두 관절이 같은 축으로 손을 돌리니, 손목 관절 셋 가운데 하나를 잃은 셈이다.

잃은 것은 어느 축으로 도는 능력일까? 손목이 손에 줄 수 있는 각속도는 θ̇₄ z₄ + θ̇₅ z₅ + θ̇₆ z₆다(7.3절). z₆ = z₄이면 이 합은 z₄와 z₅가 만드는 평면을 벗어나지 못한다.

그래서 그 평면에 수직인 축 n = z₅ × z₄로는 손을 돌릴 수 없다. 교수가 연필을 손에 대고 이리저리 돌려 보다가 "이 축으로는 잠겼다"고 보여 주는 축이 이것이다.

가까이만 가도 손목이 바빠진다

θ₅가 0이 아니어도 작으면 문제다. z₆이 n 쪽으로 기운 몫은 sin θ₅뿐이다. 그 작은 몫으로 n 방향 회전을 만들려면 관절 6이 1/sin θ₅의 빠르기로 돌아야 한다.

그러면 z₆에 딸린 z₄ 방향 몫도 함께 생긴다. 관절 4가 반대 방향으로 cos θ₅/sin θ₅의 빠르기로 돌아 그 몫을 지운다. 손을 축 n으로 1 rad/s 돌릴 때 두 관절의 빠르기는 이렇다.

θ₅ 30° 10° 3° 1°
관절 6 (rad/s) 2.00 5.76 19.1 57.3
관절 4 (rad/s, 반대 방향) 1.73 5.67 19.1 57.3

잠깐, 생각해 보기. θ₅ = 0일 때 관절 4를 +10°, 관절 6을 −10° 돌리면 손은 어떻게 되나?

손은 그대로다. 두 관절이 같은 축으로 반대만큼 돌아 서로 지운다. 관절은 움직이는데 손은 멈춰 있는 이 움직임을 교수는 "안에서만 도는 자유"라고 부른다.

θ₄와 θ₆이 얼마이든 θ₅ = 0이기만 하면 이 특이점은 그대로 남는다. 손의 방향이 θ₄ + θ₆의 합에만 달려 있기 때문이다.

8.2 특이점을 찾는 법

강의가 내리는 정의는 이렇다. 손끝이 어떤 자세에서 한 방향으로 움직이거나 한 축으로 돌 수 없게 되면, 그 자세를 기구학적 특이점(kinematic singularity)이라 한다. 그 방향을 특이 방향(singular direction)이라 한다.

자코비안으로 말하면 열들이 서로 기대어 계수가 줄어든 자세다(7.9절). 열에는 관절 축 zi가 들어 있으니, 축들이 겹치거나 나란해지면 열도 기댄다.

det J를 인수로 나눈다

자코비안이 정사각 행렬이면 det J를 관절 변수의 식으로 계산한다. 잘 정리하면 det J는 몇 개의 식을 곱한 꼴이 된다.

곱이 0이 되려면 그중 하나만 0이면 된다. 그래서 인수마다 Si(q) = 0을 풀면 특이점의 무리가 하나씩 나온다.

회전행렬은 det가 1이라 좌표계를 바꿔도 det J는 같다(7.9절). 그러니 식이 가장 간단한 좌표계를 골라 계산한다.

  • 종이 팔: det J = 80 sin θ₂다. 인수 하나, θ₂ = 0°, 180°다.
  • 스탠퍼드 팔(점 W): det J = d₃² sin θ₂ sin θ₅다(7.10절). 인수가 셋이다. d₃ = 0, θ₂ = 0° 또는 180°, θ₅ = 0° 또는 180°다.

열을 보면 바로 보인다: θ₅ = 0

det를 계산하지 않고 열만 봐도 알 수 있다. 손목점 W로 잡은 스탠퍼드 팔 자코비안(7.8절)의 4열과 6열은 이렇다.

θ₅ = 0이면 z₆ = z₄라서 두 열이 똑같아진다. 서로 기대지 않는 열이 5개로 줄어 계수가 5가 된다. 실물 팔의 "축 두 개가 한 줄"이 자코비안에서는 "열 두 개가 같다"로 나타난다.

평면 팔은 0인 줄을 빼고 본다

평면 팔의 자코비안을 6줄로 쓰면 늘 0인 줄이 셋 생긴다(7.4절). 이런 행렬은 정사각이 아니라 det를 바로 구할 수 없다. 그래서 0인 줄을 빼고, 할 일에 쓰는 줄만 남긴다. 이것을 줄인 자코비안(reduced Jacobian)이라 부르자.

  • 관절 2개로 손끝 위치만 다루면 vx, vy 두 줄을 남겨 2 × 2다.
  • 관절 3개로 손끝 위치와 방향을 다루면 vx, vy, ωz 세 줄을 남겨 3 × 3이다.

6.9절의 3관절 팔(8, 7, 5 cm)이 θ = (0°, 90°, −90°)일 때 줄인 자코비안과 det는 이렇다.

아무 자세에서나 계산하면 det J = 8 × 7 × sin θ₂ = 56 sin θ₂다. 셋째 링크의 길이도, θ₃도 들어 있지 않다. 까닭은 8.4절을 배운 뒤 문제 2에서 본다.

알아 두기. 0인 줄을 빼는 것은 지름길이다. 정사각이 아닌 행렬은 보통 JᵀJ의 det나 특이값(singular value)으로 계수를 따진다. 줄인 자코비안은 어느 줄이 늘 0인지 알 때 그 계산을 건너뛰는 방법이다.

3차원 팔의 세 가지 특이점

PUMA처럼 생긴 6관절 팔을 보자. 7.5절의 돌림판 종이 팔(돌림판, 어깨, 팔꿈치) 끝에 스탠퍼드 팔 같은 손목 세 관절을 붙인 팔이다. W로 잡으면 자코비안의 오른쪽 위가 0이 되어(7.8절), det는 두 덩어리의 det를 곱한 것이다.

r은 W에서 돌림판 축까지의 수평 거리다(7장 문제 5). 인수가 셋이라 특이점도 세 무리다.

  1. 팔꿈치 특이점(θ₃ = 0°, 180°): 팔을 쭉 펴면 W가 닿는 영역의 바깥 끝에 온다. 팔 방향으로는 더 나갈 수 없다. 닿는 영역의 경계에서 생기므로 경계 특이점(boundary singularity)이라 한다.
  2. 어깨 특이점(r = 0): W가 돌림판 축 바로 위에 온다. 돌림판을 돌려도 W는 제자리라서, 세로 판에 수직인 방향으로 W를 밀 수 없다.
  3. 손목 특이점(θ₅ = 0°, 180°): 8.1절에서 본 대로 축 4와 축 6이 한 줄이 된다.

어깨와 손목 특이점은 닿는 영역 한가운데서 생긴다. 이런 것을 내부 특이점(interior singularity)이라 한다. 경계 특이점은 손이 닿는 끝이라 피하기 쉽지만, 내부 특이점은 일하는 영역 안에 있어서 더 조심해야 한다.

잠깐, 생각해 보기. 어깨 특이점 근처에서 W를 세로 판에 수직으로 1 cm/s 밀려고 한다. r = 1 cm일 때와 r = 0.1 cm일 때 돌림판은 얼마나 빨리 돌아야 하나?

돌림판이 θ̇₁로 돌면 W는 반지름 r인 원을 따라 r θ̇₁의 빠르기로 움직인다. 그러니 θ̇₁ = 1/r이다.

r = 1 cm이면 1 rad/s, r = 0.1 cm이면 10 rad/s다. 손목점이 돌림판 축을 스치는 길을 시키면 돌림판이 갑자기 휙 돌아야 한다.

8.3 PUMA 시뮬레이션: 문제는 특이점 근처다

강의 예제: 쭉 편 종이 팔

강의는 2관절 팔로 돌아간다. 7.7절의 ¹J(링크 1의 좌표계로 적은 J)에 θ₂ = 0°를 넣는다.

첫 줄이 0이라 δθ₁, δθ₂를 어떻게 넣어도 δx₁ = 0이다. x₁은 링크 1 방향, 곧 쭉 편 팔이 놓인 방향이다. 어깨를 돌리든 팔꿈치를 돌리든 손끝은 같은 원의 접선 방향(y₁)으로만 간다.

화면 속 PUMA를 끌어 보기

교수는 이어서 컴퓨터 속 PUMA를 보여 준다. 중력을 상쇄해 팔이 둥둥 떠 있어서, 손끝에 힘을 걸어 끌면 그쪽으로 따라온다.

팔을 거의 편 채 팔 방향으로 끌면 겨우 움직이고 아주 무겁다. 다 편 자세에서는 아무리 세게 끌어도 팔 방향으로는 꿈쩍하지 않는다.

다른 방향으로 끌면 바로 움직인다. 그 까닭은 8.9절에서 힘 쪽으로 다시 본다.

θ₂ = ε일 때의 역행렬

특이점 위만 피하면 될까? 강의의 대답은 "아니다"다. 가까워지기만 해도 J는 조건이 나쁜 행렬이 되고, J⁻¹에 큰 수가 생긴다(7.10절).

θ₂가 아주 작은 각 ε(라디안)이라 하자. sin ε ≈ ε, cos ε ≈ 1로 어림하면 ¹J ≈ [[−8ε, −8ε], [18, 8]]이고, det는 80ε이다. 역행렬은 이렇다.

손끝 속도를 {1}의 숫자 (ẋ₁, ẏ₁)로 주면 관절 속도는 다음과 같다.

ε로 나누는 것은 팔 방향 몫 ẋ₁뿐이다. 팔에 수직인 몫 ẏ₁은 ε과 상관없이 쉽다. 특이점 근처에서 터지는 것은 특이 방향의 명령이다.

ε = 2°(0.035 rad)에서 팔 방향으로 겨우 1 mm/s를 원한다고 하자. 팔꿈치는 9 × 0.1 ÷ (40 × 0.035) ≈ 0.64 rad/s로 돌아야 한다. 7.10절의 표와 같은 이야기를 식으로 본 것이다.

ε이 음수(팔꿈치가 반대쪽으로 조금 굽은 자세)이면 1/ε의 부호가 뒤집힌다. 0의 양쪽에서 각각 +∞와 −∞로 가는 그래프가 강의에 나온다. 어느 쪽에서 다가가든 필요한 관절 속도는 끝없이 커지고, 특이점 위에서는 어떤 값으로도 안 된다.

8.4 속도를 재는 점 옮기기

7장에서 스탠퍼드 팔의 자코비안은 손목점 W에서 구했다. 식이 가장 간단하기 때문이다.

그런데 일은 집게 끝이나 쥔 공구의 끝 E에서 한다. W와 E 사이는 손에 고정된 화살표 pWE 하나다.

각속도는 같고, 선속도에 ω × p가 더해진다

W와 E는 같은 손(마지막 링크)에 붙어 있다. 그래서 둘의 속도 관계는 6.6절의 "도는 물체 위의 점"과 같다.

강의에서 학생 몇이 "vE = vW"라고 답하자 교수가 6장의 사과 꼬챙이를 떠올리게 한다. W가 멈춰 있어도 손이 돌면 E는 움직인다.

ω × p = −p × ω = −p̂ ω다(6.7절의 외적 연산자). 그래서 두 식을 행렬 하나로 묶는다. 이 관계는 어느 q̇에서나 맞으므로 자코비안끼리도 같은 행렬로 이어진다.

I는 3 × 3 단위행렬이다. 각속도 쪽(아래 덩어리)은 그대로이고, 선속도 쪽에만 −p̂ Jω가 더해진다.

예: 3관절 팔의 손목에서 손끝으로

6.9절의 3관절 팔(8, 7, 5 cm)을 θ = (0°, 90°, −90°)에 둔다. 셋째 관절 자리를 손목 W = (8, 7)로, 손끝을 E = (13, 7)로 본다. pWE = (5, 0)이다.

JW의 열은 7.4절처럼 관절에서 W까지의 화살표를 90° 돌려 얻는다. 셋째 관절은 W를 지나는 축이라 셋째 열의 위 칸이 0이다.

평면에서는 ω × p = (−ω py, ω px)라서 옮기는 행렬도 3 × 3으로 줄어든다. py = 0, px = 5를 넣는다.

6.9절에서 손끝을 직접 미분해 얻은 J, 8.2절의 J와 같다. 둘째 줄에 마지막 줄 × 5를 더한 것뿐이다.

그림의 숫자를 확인하자. vW = JW θ̇ = (−7, 4) cm/s이고 ω = 0.5 + 0.5 + 0 = 1 rad/s다. ω × pWE = (0, 5)를 더하면 vE = (−7, 9) cm/s다. JE θ̇로 바로 구해도 같다.

잠깐, 생각해 보기. 셋째 관절만 1 rad/s로 돌리면(θ̇ = (0, 0, 1)) vW와 vE는 얼마인가?

vW = 0이다. 셋째 관절의 축이 W를 지나기 때문이다(JW의 셋째 열 위 칸이 0).

손은 1 rad/s로 돌고, vE = ω × p = (0, 5) cm/s다. JE의 셋째 열 (0, 5, 1)이 바로 이것이다.

좌표계를 맞춘다

숫자로 계산할 때는 pWE도 JW와 같은 좌표계로 적어야 한다. pWE는 보통 손 좌표계 {n}에서 간단하다. 공구가 zn을 따라 7 cm 나와 있으면 ⁿp = (0, 0, 7)이다.

JW가 {0}의 숫자라면 p̂도 {0}의 숫자여야 한다. 가장 쉬운 길은 p를 먼저 {0}으로 돌리고 나서 모자를 씌우는 것이다.

모자를 먼저 씌운 행렬을 옮기려면 앞뒤로 곱해야 한다. ⁰p̂ = ⁰ₙR ⁿp̂ ⁰ₙRᵀ다. 앞에만 R을 곱하면 틀린다.

강의에서 교수가 "이 실수를 하지 말라"고 짚는 부분이다.

수학 더하기: 왜 앞뒤로 곱하나. p̂는 화살표가 아니라 "화살표를 받아 화살표를 내놓는" 행렬이다. ⁰p̂ ⁰ω를 차례로 따라가 보자.

먼저 Rᵀ가 ⁰ω를 {n}의 숫자로 바꾼다. 다음에 ⁿp̂가 {n}에서 외적을 한다. 마지막에 R이 결과를 {0}으로 되돌린다.

그래서 R ⁿp̂ Rᵀ다.

8.5 손끝 속도로 팔 움직이기: resolved-rate 제어

자코비안은 속도를 분석하는 데만 쓰지 않는다. 팔을 움직이는 데도 쓴다. 강의에 따르면 많은 로봇이 자코비안 하나로 손끝을 움직인다.

작은 걸음을 이어 붙인다

손끝을 목표 xd로 보내고 싶다고 하자. 특이점에서 떨어져 있으면 J⁻¹이 있으니, 다음을 되풀이한다.

  1. 관절 각도 θ를 잰다(모터의 각도 센서).
  2. 순기구학으로 지금 손끝 x = f(θ)를 구한다.
  3. 목표와의 차이 δx = xd − x를 구한다. J를 쓰려면 이 차이가 작아야 한다.
  4. δθ = J(θ)⁻¹ δx를 구한다.
  5. 관절마다 θ + δθ로 가라고 명령하고, 1로 돌아간다.

같은 생각을 속도로 쓰면 이렇다. 원하는 손끝 속도 ẋd를 관절 속도로 "풀어서"(resolve) 관절마다 나눠 준다.

이 방법을 resolved-rate 제어(resolved motion rate control)라 한다. 1970년 무렵 Daniel Whitney가 내놓았다. 동역학도 접촉 힘도 생각하지 않는 아주 단순한 방법이다.

시간 간격 Δt로 걷기

컴퓨터는 이 계산을 Δt마다 한 번씩 한다. 두 가지 방법을 견주어 보자.

  • 속도만 더하기: θk+1 = θk + J⁻¹ ẋd Δt. 손끝이 어디 있는지 다시 재지 않는다.
  • 손끝을 다시 재기: θk+1 = θk + J⁻¹ (xd(tk+1) − f(θk)). 위의 1~5단계 그대로다.

J는 지금 자세의 접선 방향만 안다(6.3절). 그래서 걸음마다 조금씩 빗나간다. 속도만 더하면 빗나감이 쌓이고, 다시 재면 다음 걸음에서 고친다.

해 볼 것 두 가지:

  1. 걸음 수를 8(Δt = 1초)로 둔다. 속도만 더하면 끝에서 2.4 cm 빗나가고, 다시 재면 0.26 cm다.
  2. 걸음 수를 32(Δt = 0.25초)로 늘린다. 둘 다 좋아지지만 다시 재기가 훨씬 빨리 좋아진다. 0.56 cm 대 0.016 cm다.

알아 두기. 목표를 움직이지 않고 "다시 재기" 걸음을 되풀이하면 두세 걸음 만에 손끝이 목표에 거의 정확히 닿는다(문제 5). 역기구학을 숫자로 푸는 방법이기도 하다.

다만 이 방법은 느리고 작게 움직일 때 잘 된다. 빠르게 움직이면 가속도와 동역학을 무시한 탓에 오차가 커진다. 강의도 이 한계를 짚는다.

8.6 특이점 가까이에서 생기는 일

이번에는 resolved-rate 제어로 손끝을 닿는 영역의 끝 쪽으로 곧게 보내 보자. 손끝을 y = 5 cm인 선을 따라 x = 10 cm에서 17.29 cm까지 1 cm/s로 옮긴다. 끝점은 팔을 거의 다 편 자세(θ₂ ≈ 1.5°)다.

해 볼 것 두 가지:

  1. λ = 0에서 시간을 처음부터 끝까지 민다. 7초까지 팔꿈치는 기껏해야 0.6 rad/s로 느긋하다. 그런데 마지막 0.3초 사이에 8 rad/s까지 치솟는다.
  2. λ를 1로 올린다. 관절 속도가 0.7 rad/s 아래로 눌린다. 대신 팔이 끝까지 펴지지 않고(θ₂ ≈ 13°), 손끝이 목표보다 0.1 cm쯤 덜 간다.

무엇이 잘못되나

손끝 속도는 끝까지 1 cm/s로 아무 문제가 없어 보인다. 그런데 그 속도에는 팔 방향 몫이 남아 있고, θ₂는 0으로 간다. 8.3절의 1/ε 때문에 관절 속도가 끝없이 커진다.

진짜 모터는 속도 한계가 있어서 따라가지 못한다. 손끝이 길을 벗어나거나 팔이 덜컥거린다. 그래서 실제 로봇은 이렇게 한다.

  • 특이점을 지나거나 스치는 길을 애초에 짜지 않는다.
  • 특이점에 가까워지면 손끝 속도를 줄인다.
  • J⁻¹ 대신, 특이점 근처에서도 터지지 않는 식을 쓴다.

감쇠 최소제곱

세 번째 방법 가운데 널리 쓰는 것이 감쇠 최소제곱(damped least squares)이다. λ는 길이(cm) 단위의 작은 수다.

λ = 0이면 J⁻¹ẋd와 같다. λ > 0이면 손끝 속도를 조금 덜 정확하게 맞추는 대신 관절 속도를 아낀다. 어떤 자세에서도 관절 속도의 크기가 |ẋd|/(2λ)를 넘지 않는다.

λ를 아주 크게 하면 관절 속도는 아주 작아지지만 손끝도 거의 움직이지 않는다. 그래서 λ는 특이점 근처에서만 키우고, 멀리서는 0에 가깝게 두는 경우가 많다.

8.7 문 열기: 속도와 힘은 짝이다

강의의 마지막 주제는 정적 힘(static force)이다. 팔이 멈춘 채로 손끝으로 무엇을 누르거나 버틸 때, 관절이 내야 할 토크를 구한다. 여기서도 답은 같은 자코비안이다.

교수는 연구실 문을 여는 사진으로 시작한다. 손잡이를 돌리고 문을 밀면 문은 경첩 축으로 돈다. 문은 자유도가 1인 기구다.

  • 속도: 문이 각속도 ω로 돌면 점 P의 속도는 v = ω × p다(6.6절).
  • 힘: 점 P를 힘 F로 밀면 경첩 축에 생기는 토크는 τ = p × F다. 이번에는 p가 앞에 온다(6.6절에서 미리 말한 대로).

숫자로 해 보자. 경첩에서 0.7 m 떨어진 곳을 문판에 수직으로 20 N으로 밀면 τ = 0.7 × 20 = 14 N·m다. 문이 0.5 rad/s로 돌면 그 점은 0.7 × 0.5 = 0.35 m/s로 움직인다.

두 식을 행렬로 쓰면

외적 연산자(6.7절)로 두 식을 행렬로 쓴다. 외적은 순서를 바꾸면 부호가 바뀌므로 v = ω × p = −p × ω다.

p̂는 반대칭 행렬이라 p̂ᵀ = −p̂다. 그러니 τ = p̂F = (−p̂)ᵀF다. 속도를 옮기는 행렬을 J라 하면, 힘을 거꾸로 옮기는 행렬은 그 전치다.

이것이 1장에서 이름만 들은 속도·힘 쌍대성(velocity–force duality)이다.

평면에서 확인해 보자. 문이 책상 면처럼 수평으로 돌고 축이 z라면 p = (px, py)다.

같은 칸 (−py, px)가 세로로 서면 속도를, 가로로 누우면 힘을 옮긴다. 종이 팔 자코비안의 첫 열 (−y, x)와 같은 모양이다(6.3절).

잠깐, 생각해 보기. 문판을 따라 경첩 쪽으로 밀면 문은 어떻게 되나? 그림 8-6의 회색 점선 방향이다.

문은 돌지 않는다. F가 p와 나란하면 p × F = 0이다. 문 위의 점은 그 방향으로 움직일 수도 없다.

속도가 못 나오는 방향과, 힘이 토크를 못 만드는 방향이 같다. 8.9절의 특이 자세에서 같은 일이 생긴다.

8.8 손끝 힘에서 관절 토크로: τ = Jᵀ F

손끝의 힘과 모멘트

손끝은 바깥에 힘 f(숫자 3개)를 주고, 비트는 모멘트(moment) n(숫자 3개)도 줄 수 있다. 드라이버로 나사를 돌리는 것이 모멘트다.

둘을 모은 숫자 6개를 F라 쓴다. 선속도 v, 각속도 ω와 짝을 이룬다.

이 장에서 F는 손끝이 바깥에 주는 힘이다. 바깥이 손끝을 미는 힘은 그 반대인 −F다. 관절이 내는 힘(회전 관절은 토크, 직동 관절은 미는 힘)을 모아 τ라 쓴다.

방법 1: 링크마다 평형 잡기

속도 전파(6.8절)처럼 힘도 링크에서 링크로 넘길 수 있다. 이번에는 손끝에서 출발해 받침 쪽으로 간다. 이것을 힘 전파(force propagation)라 한다.

링크 i가 멈춰 있으려면 걸린 힘의 합이 0이고, 한 점에 대한 모멘트의 합도 0이어야 한다. 링크 i는 받침 쪽 관절 i에서 fi, ni를 받고, 손끝 쪽 관절 i+1에서 −fi+1, −ni+1을 받는다. 관절 i의 원점에 대한 모멘트로 정리하면 이렇다.

pi,i+1은 관절 i의 원점에서 관절 i+1의 원점까지의 화살표다. 관절 모터는 이 가운데 자기 축 방향 몫만 낸다. 나머지는 베어링과 링크 구조가 받는다.

종이 팔로 해 보자. 손끝이 힘 f를 준다. 팔꿈치 모멘트는 n₂ = p2E × f다. 어깨까지 오면 n₁ = n₂ + p₁₂ × f = p1E × f다(p₁₂ + p2E = p1E).

그래서 관절 i의 토크는 "손끝 힘이 관절 i의 축에 만드는 모멘트"다. 세 벡터의 곱을 바꿔 쓰면 낯익은 모양이 나온다.

수학 더하기: 세 벡터의 곱. a · (b × c) = (a × b) · c다. 세 화살표가 만드는 평행육면체의 부피(부호 포함)라서, 순서만 지키면 점과 곱의 자리를 바꿔도 값이 같다.

예: a = (0, 0, 1), b = (1, 0, 0), c = (0, 2, 0)이다. b × c = (0, 0, 2)라서 a · (b × c) = 2다. a × b = (0, 1, 0)이라서 (a × b) · c = 2로 같다.

zi × piE는 7.2절에서 본 자코비안의 i번째 열이다. 그러니 τi는 "J의 i번째 열 · f"이고, 모두 모으면 τ = Jvᵀ f다. 손끝 모멘트 n까지 넣으면 τ = JᵀF가 된다.

방법 2: 가상일

힘 전파는 링크 사이에서 주고받는 내부 힘(internal force)을 일일이 구했다가 지운다. 가상일의 원리(principle of virtual work)를 쓰면 내부 힘을 처음부터 생각하지 않아도 된다.

수학 더하기: 일과 일률. 힘 F로 물체를 δx만큼 밀면 일(work)은 F · δx다. 힘과 같은 방향으로 움직인 몫만 센다. 토크 τ로 δθ만큼 돌리면 일은 τ δθ다.

일을 걸린 시간으로 나눈 것이 일률(power)이다. F · ẋ나 τ θ̇로 쓴다.

내부 힘은 일을 하지 않는다. 링크 구조가 그 힘을 받아 버틸 뿐, 그 방향으로는 아무것도 움직이지 않기 때문이다. 일을 하는 것은 관절 토크 τ와 손끝 힘 F뿐이다.

팔이 멈춰 버티고 있을 때, 관절을 아주 조금 δq 움직였다고 상상하자. 실제로는 움직이지 않으니 "가상" 변위다. 손끝은 δx = J δq만큼 움직인다.

모터가 한 일은 τᵀδq다. 평형이면 그 일이 고스란히 손끝을 통해 바깥으로 나가므로 Fᵀδx와 같다.

이 식은 어떤 δq에서나 맞아야 한다. δq = (1, 0)을 넣으면 τ₁이, (0, 1)을 넣으면 τ₂가 정해진다. 그러니 δq 앞의 숫자가 칸마다 같고, 전치하면 답이 나온다.

δ를 시간으로 나누면 일률이 같다는 말이 된다. 모터가 넣는 일률이 손끝에서 나가는 일률이다.

숫자로 확인

종이 팔이 θ = (30°, 60°)에 있다. J = [[−13, −8], [8.66, 0]]이다(6.3절). 손끝이 −x 방향으로 F = (−1, 0) N을 준다.

길이를 cm로 쟀으니 토크의 단위는 N·cm다(100 N·cm = 1 N·m). 6.3절처럼 θ̇ = (0.5, 1) rad/s로 움직이면 ẋ = (−14.5, 4.33) cm/s다.

일률을 맞춰 보자. τᵀθ̇ = 13 × 0.5 + 8 × 1 = 14.5이고, Fᵀẋ = (−1)(−14.5) + 0 × 4.33 = 14.5다. 둘 다 14.5 N·cm/s로 같다.

알아 두기. 숙제나 다른 책에서는 "손끝에 걸린 힘을 버틴다"고 쓸 때가 많다. 걸린 힘이 Fext이면 손끝이 주는 힘은 −Fext라서 τ = −JᵀFext다. 계산하기 전에 부호부터 정한다.

8.9 강의 예제: 1 N과 1000 N

1 N 버티기

강의 예제는 링크 길이가 1 m, 1 m인 2관절 팔이다. θ₁ = 0°, θ₂ = 60°에서 손끝이 아래(−y)로 1 N을 준다. s₁ = 0, c₁ = 1, s₁₂ ≈ 0.866, c₁₂ = 0.5다.

어깨의 1.5 N·m는 1 N × 1.5 m다. 손끝이 어깨에서 가로로 1.5 m 떨어져 있기 때문이다.

팔꿈치의 0.5 N·m도 팔꿈치에서 손끝까지의 가로 거리 0.5 m에서 나온다. 음수는 시계 방향으로 비틀어야 한다는 뜻이다.

1000 N을 토크 0으로

이번에는 θ₁ = 90°, θ₂ = 0°로 팔을 똑바로 세우고, 손끝이 아래로 1000 N을 준다. c₁ = c₁₂ = 0이라 Jᵀ의 둘째 열이 0이다.

모터는 아무 토크도 내지 않는다. 힘이 팔을 따라 곧게 내려가서 받침이 다 받는다. 특이 자세에서는 특이 방향으로 움직일 수 없는 대신, 그 방향의 힘을 토크 없이 버틴다.

무거운 것을 들 때 팔다리를 펴는 까닭이다. 강의도 이 말로 끝난다. 특이 자세 근처에서는 작은 토크로 아주 큰 힘을 낸다.

8.3절의 "아주 무거운 PUMA"도 이것으로 설명된다. 팔 방향으로 거는 힘은 관절 토크 JᵀF를 거의 만들지 못한다. 그러니 관절이 돌지 않는다.

τ = Jωᵀ nz = (1, 1) × 2 = (2, 2) N·cm다. 힘이 없으니 지렛대 몫(p × f)이 생기지 않는다. 모멘트는 링크를 따라 그대로 받침까지 전해지고, 두 관절이 같은 토크로 버틴다.

속도 타원과 힘 타원

같은 J가 속도와 힘을 옮기니, 둘 사이에는 깔끔한 관계가 있다. 관절 속도를 길이 1인 원에서 고르면 손끝 속도는 타원 위에 놓였다(7.10절). 관절 토크를 원에서 고르면 손끝 힘 F = (Jᵀ)⁻¹τ도 타원 위에 놓인다.

두 타원의 축은 같은 방향을 보고, 길이는 서로 거꾸로다. 이 자세에서 속도 타원은 팔에 거의 수직으로 19 cm/s, 팔 방향으로 2.1 cm/s다. 힘 타원은 팔 방향으로 4.8 N, 팔에 수직으로 0.53 N이다.

특이점에 가까울수록 속도 타원은 납작해지고, 힘 타원은 팔 방향으로 끝없이 길어진다. 8.3절의 "무거운 방향"과 8.9절의 "토크 없이 버티는 방향"이 같은 방향이다.

생기지 않는다. 힘 f가 pWE와 나란하면 p × f = 0이다.

비스듬히 누르면 손목이 비틀린다. 나사를 곧게 눌러야 손목이 편한 까닭이다.

import numpy as np

np.set_printoptions(precision=2, suppress=True)
D = np.pi / 180

def hat(a):
    """외적 연산자: hat(a) @ b == np.cross(a, b)."""
    return np.array([[0, -a[2], a[1]], [a[2], 0, -a[0]], [-a[1], a[0], 0]])

def fk(q):
    """종이 팔의 손끝 (q는 라디안)."""
    return np.array([10 * np.cos(q[0]) + 8 * np.cos(q[0] + q[1]),
                     10 * np.sin(q[0]) + 8 * np.sin(q[0] + q[1])])

def J2(q, l1=10, l2=8):
    """2관절 평면 팔의 자코비안 (q는 라디안)."""
    s1, c1, s12, c12 = np.sin(q[0]), np.cos(q[0]), np.sin(q[0] + q[1]), np.cos(q[0] + q[1])
    return np.array([[-l1 * s1 - l2 * s12, -l2 * s12], [l1 * c1 + l2 * c12, l2 * c12]])

def ik(x):
    """종이 팔의 역기구학 (θ2 > 0 쪽)."""
    t2 = np.arccos(np.clip((x @ x - 164) / 160, -1, 1))
    return np.array([np.arctan2(x[1], x[0]) - np.arctan2(8 * np.sin(t2), 10 + 8 * np.cos(t2)), t2])

def planar3(t, l=(8, 7, 5)):
    """3관절 평면 팔: [관절 1, 관절 2, 관절 3 = W, 손끝 E] 위치 (t는 도)."""
    a, pts = np.cumsum(np.radians(t)), [np.zeros(2)]
    for li, ai in zip(l, a):
        pts.append(pts[-1] + li * np.array([np.cos(ai), np.sin(ai)]))
    return pts

def J_planar(joints, point):
    """줄인 자코비안 (vx, vy, ωz): 열 = z × (point − 관절), 맨 아래는 1."""
    return np.array([[-(point - o)[1], (point - o)[0], 1] for o in joints]).T

def shift(p):
    """평면에서 점을 p만큼 옮기는 행렬 [[I, -p^], [0, I]]."""
    return np.array([[1, 0, -p[1]], [0, 1, p[0]], [0, 0, 1]])

# 8.2 스탠퍼드 팔 (7장의 DH 표, 점 W): θ5 = 0이면 4열 = 6열, 계수 5
def dh(alpha, a, d, theta):
    ca, sa, ct, st = np.cos(alpha * D), np.sin(alpha * D), np.cos(theta * D), np.sin(theta * D)
    return np.array([[ct, -st, 0, a], [st * ca, ct * ca, -sa, -sa * d],
                     [st * sa, ct * sa, ca, ca * d], [0, 0, 0, 1]])

def stanford_J(q, d2=15):
    t1, t2, d3, t4, t5, t6 = q
    rows = [(0, 0, 0, t1), (-90, 0, d2, t2), (90, 0, d3, 0), (0, 0, 0, t4), (-90, 0, 0, t5), (90, 0, 0, t6)]
    T, Ts = np.eye(4), []
    for r in rows:
        T = T @ dh(*r)
        Ts.append(T)
    W, cols = Ts[-1][:3, 3], []
    for kind, T in zip('RRPRRR', Ts):
        z, o = T[:3, 2], T[:3, 3]
        cols.append(np.r_[np.cross(z, W - o), z] if kind == 'R' else np.r_[z, 0, 0, 0])
    return np.array(cols).T
