종이 팔로 배우는 로봇공학 입문

스탠퍼드 대학 CS223A 「로봇공학 입문」(Oussama Khatib 교수, 2008년, 16강)을 혼자 공부하려고 한국어로 새로 쓴 교재다. 책상 위 종이 팔 하나를 예로 들어, 그림과 직접 움직여 보는 그림으로 설명한다.

목차

1장. 로봇 팔은 무엇을 풀어야 하나강의 1강 · 순기구학, 역기구학, 자코비안, 동역학, 제어를 수식 없이 그림으로 2장. 위치와 방향을 숫자로 적기강의 2강 · 자유도, 회전행렬, 동차변환 · 연습문제와 파이썬 확인 코드

이 교재로 공부하는 법

  1. 장을 먼저 읽는다. 슬라이더가 있는 그림은 직접 움직여 본다.
  2. 절마다 있는 "영상에서 보기" 링크로 강의의 그 장면을 본다. 강의는 영어이고 유튜브에서 영어 자막을 켤 수 있다.
  3. "잠깐, 생각해 보기"에서 멈추고 답을 적어 본다.
  4. 장 끝 문제를 손으로 푼다.

준비물

필요한 것 처음 나오는 곳
고등학교 삼각함수 (sin, cos) 1장
벡터와 내적 2장 (본문에서 설명한다)
행렬 곱하기 2장 (본문에서 설명한다)
파이썬 (없어도 된다) 2장 끝 확인 코드

강의와 자료

  • 강의 영상: 유튜브 재생목록
  • 전사본, 유인물, 숙제와 풀이: Stanford Engineering Everywhere CS223A
