<p class="lead">PD 제어의 두 이득은 닫힌 루프가 얼마나 빨리, 얼마나 출렁이며 목표에 가는지를 정한다. 이 장은 이득을 고르는 법, 모델로 질량과 중력을 덜어 내는 제어 분할, 궤적 따라가기, 외란이 남기는 오차와 적분 항, 기어가 만드는 유효 관성을 차례로 익힌다. 강의 14강(73분)에 해당한다.</p>

## 14.1 13장에서 이어서: PD는 가상의 용수철과 댐퍼

강의는 촉각 센서 영상으로 시작한다. 손끝 모양의 투명한 몸통에 빛을 가두고, 고무 덮개가 눌린 자리에서 새어 나온 빛을 카메라로 찍어 닿은 곳을 읽는다. 압력 센서를 촘촘히 깔고 선을 하나하나 뽑는 대신, 영상 하나로 보내는 생각이다.

13장에서는 질량–용수철–댐퍼 m ẍ + b ẋ + k x = 0의 움직임이 두 숫자로 정해지는 것을 보았다. 고유 진동수 ω<sub>n</sub> = √(k/m)와 감쇠비 ζ = b / (2√(km))다. 모터 힘을 위치 에너지의 기울기(용수철)로 만들면 안정하고, 속도에 맞서는 힘(댐퍼)을 더하면 목표에 멈춘다는 것도 보았다.

이 둘을 합친 것이 PD 제어였다. 이 장은 그 PD의 이득을 어떻게 고르고, 모델로 어떻게 도울지를 다룬다.

### 이 장의 예: 레일 위 블록

받침 위 레일을 미끄러지는 블록 하나를 생각한다. 직동 관절 하나짜리 로봇이다.

질량 m = 2 kg이고, 모터가 레일 방향으로 힘 F를 낸다. 운동 방정식은 m ẍ = F 하나다.

목표 위치 x<sub>d</sub>로 보내는 PD 제어는 다음과 같다. k<sub>p</sub>를 **위치 이득**(position gain), k<sub>v</sub>를 **속도 이득**(velocity gain)이라 한다.

```latex
F = -k_p\,(x - x_d) - k_v\,\dot x
```

이 F를 운동 방정식에 넣고 왼쪽으로 옮긴다.

```latex
m\,\ddot x + k_v\,\dot x + k_p\,(x - x_d) = 0
```

13장의 질량–용수철–댐퍼와 같은 꼴이다. 다른 점은 용수철이 늘어나지 않은 자리가 0이 아니라 x<sub>d</sub>라는 것뿐이다.

@fig fig14_1 | 모터 힘 하나가 용수철과 댐퍼 노릇을 한다 | 그림 14-1 · PD 제어는 가상의 용수철과 댐퍼 | 용수철은 목표 x<sub>d</sub>에, 댐퍼는 받침에 붙어 있다. 그래서 블록은 x<sub>d</sub>에 와서 멈춘다.

실제로 용수철은 없다. 센서로 x와 ẋ를 재고, 컴퓨터가 F를 계산하고, 모터가 그 힘을 낸다. 이 고리를 **닫힌 루프**(closed loop)라 한다.

13장의 자연계에서는 k와 b가 정해져 있었지만, 이제는 k<sub>p</sub>와 k<sub>v</sub>를 우리가 고른다.

> **잠깐, 생각해 보기.** k<sub>p</sub>를 음수로 넣으면 블록은 어떻게 될까?

용수철이 거꾸로 밀어낸다. 목표에서 조금만 벗어나도 더 멀리 밀려나서 점점 빨라진다.

강의의 PUMA 시뮬레이터에서 이득을 −20으로 넣자 팔이 멈추지 않고 돌아간다. 이득은 양수여야 한다.

## 14.2 닫힌 루프의 고유 진동수와 감쇠비

닫힌 루프 식을 m으로 나눈다.

```latex
\ddot x + \frac{k_v}{m}\,\dot x + \frac{k_p}{m}\,(x - x_d) = 0
```

13장의 표준형과 나란히 놓고 칸끼리 맞춘다.

```latex
\ddot x + 2\zeta\omega_n\,\dot x + \omega_n^2\,(x - x_d) = 0
```

그러면 두 숫자가 나온다. **닫힌 루프 고유 진동수**(closed-loop natural frequency)와 **닫힌 루프 감쇠비**(closed-loop damping ratio)다.

```latex
\omega_n = \sqrt{\frac{k_p}{m}},\qquad \zeta = \frac{k_v}{2\sqrt{m\,k_p}}
```

13장의 공식에서 k를 k<sub>p</sub>로, b를 k<sub>v</sub>로 바꾼 것이다. k<sub>p</sub>는 ω<sub>n</sub>과 ζ 둘 다에 들어 있고, k<sub>v</sub>는 ζ에만 들어 있다.

### 숫자로 해 보기

블록(m = 2 kg)에 k<sub>p</sub> = 200 N/m, k<sub>v</sub> = 16 N·s/m을 준다.

- ω<sub>n</sub> = √(200/2) = 10 rad/s. 진동수로는 ω<sub>n</sub>/2π ≈ 1.6 Hz, 1초에 1.6번 흔들리는 빠르기다.
- ζ = 16 / (2√(2 × 200)) = 16/40 = 0.4. 1보다 작아서 출렁인다.

목표가 0초에 0에서 10 cm로 한 번에 뛰었을 때 x가 따라가는 모양을 **계단 응답**(step response)이라 한다. 얼마나 넘치는지, 언제 가라앉는지를 보면 이득이 좋은지 알 수 있다.

> **수학 더하기: 넘침은 얼마나 되나.** ζ < 1이면 응답은 출렁이는 cos 모양에, 시간이 지나며 줄어드는 껍질 e<sup>−ζω<sub>n</sub>t</sup>를 곱한 꼴이다. 출렁임의 빠르기는 ω<sub>d</sub> = ω<sub>n</sub>√(1 − ζ²)이고, 첫 봉우리는 반 주기 t<sub>p</sub> = π/ω<sub>d</sub>에 온다. **넘침**(overshoot)은 그때의 껍질 크기라서 아래 식이 된다.

```latex
M_p = e^{-\zeta\omega_n t_p} = e^{-\pi\zeta/\sqrt{1-\zeta^2}}
```

ζ = 0.4이면 √(1 − 0.16) = 0.917이라 M<sub>p</sub> = e<sup>−1.37</sup> = 0.25다. 목표 10 cm를 25% 넘어 12.5 cm까지 갔다가 돌아온다. 봉우리 시각은 t<sub>p</sub> = π / 9.17 = 0.34초다.

목표의 2% 안에 들어와서 다시 나가지 않는 시각을 **정착 시간**(settling time)이라 한다. 어림은 4/(ζω<sub>n</sub>)이고, 이 예에서는 1초다. 실제로 계산하면 0.84초다.

1. k<sub>v</sub> = 0: ζ = 0이다. 20 cm까지 넘쳤다가 0으로 돌아오기를 끝없이 되풀이한다.

4번처럼 k<sub>p</sub>만 바꿔도 감쇠비가 따라 바뀐다. 그래서 이득은 하나씩 따로 고르지 않고, ω<sub>n</sub>과 ζ를 먼저 정한 다음 거꾸로 구한다. 다음 절의 방법이다.

## 14.3 임계 감쇠와 이득 고르기

로봇은 대개 ζ = 1을 고른다. 이것을 **임계 감쇠**(critical damping)라 한다. 까닭은 두 가지다.

- **넘치면 부딪힌다.** 손끝이 목표를 지나치면 집으려던 컵이나 책상을 친다.
- **너무 감쇠하면 느리다.** ζ > 1이면 넘치지는 않지만 목표에 슬금슬금 다가간다.

ζ = 1은 넘치지 않는 응답 가운데 가장 빠르다. 조건은 ζ = 1을 풀면 나온다.

```latex
k_v = 2\sqrt{m\,k_p}
```

블록이면 k<sub>v</sub> = 2√(2 × 200) = 40 N·s/m이다. 그림 14-2의 회색 점선이 이것이다.

> **잠깐, 생각해 보기.** 그림 14-2에서 k<sub>v</sub> = 32(ζ = 0.8)로 하면 0.37초에 2% 안에 든다. ζ = 1의 0.58초보다 빠르다. 그런데 왜 ζ = 1을 고를까?

ζ = 0.8은 1.5% 넘친다. 넘침이 2% 띠 안이라 정착 시간은 짧게 나오지만, 손끝은 목표를 지나친다. 물건에 닿는 일에서는 조금만 지나쳐도 민다.

게다가 팔의 질량은 자세마다 바뀌어서(14.4절) 실제 ζ는 계산보다 낮아질 수 있다.

### ω와 ζ를 정하고 이득을 구한다

ω<sub>n</sub>과 ζ의 공식을 이득에 대해 풀면 설계 순서가 나온다.

```latex
k_p = m\,\omega_n^2,\qquad k_v = 2\,m\,\zeta\,\omega_n
```

ζ는 대개 1로 둔다. 그러면 남은 일은 ω<sub>n</sub> 하나를 고르는 것이다. ω<sub>n</sub> = 10 rad/s, ζ = 1이면 블록의 이득은 k<sub>p</sub> = 200, k<sub>v</sub> = 40이다.

### ω는 얼마나 높일 수 있나

ω<sub>n</sub>을 올리면 응답이 빨라진다. k<sub>p</sub>도 함께 커져서 팔이 단단해진다. 손으로 밀어도 덜 밀리고, 다른 관절이 흔드는 힘에도 덜 흔들린다.

강의의 PUMA 시뮬레이터가 이것을 보여 준다. 관절 2를 당겼다 놓으면 관절 3이 따라 흔들린다. 이득을 40에서 400, 1600으로 올릴수록 흔들림이 줄고 빨리 제자리로 간다.

그런데 끝없이 올릴 수는 없다. 기어, 벨트, 링크는 조금씩 휘어서 저마다 흔들리기 좋아하는 **공진 진동수**(resonance frequency)가 있다. 닫힌 루프의 ω<sub>n</sub>이 그 근처에 가면 구조가 떨리기 시작하고 결국 불안정해진다.

어림 규칙으로 ω<sub>n</sub>은 구조의 가장 낮은 공진 진동수의 절반 아래로 둔다(Craig 교재). 강의의 k<sub>p</sub> = 400(m = 1)은 ω<sub>n</sub> = 20 rad/s, 약 3.2 Hz다. 산업용 팔에서 10 Hz면 아주 잘한 것이다.

실제로는 낮은 이득에서 시작해 조금씩 올린다. 떨리는 소리가 나기 시작하면 한 단계 내린다.

> **알아 두기.** 이득의 한계는 공진만이 아니다. 모터는 낼 수 있는 힘에 끝이 있어서, 큰 오차에 큰 k<sub>p</sub>를 곱하면 힘이 모자라 포화된다. 속도는 보통 엔코더 각도를 미분해 얻기 때문에 잡음이 많고, k<sub>v</sub>가 그 잡음을 그대로 키워 모터를 떨게 한다.

같은 ω<sub>n</sub> = 10 rad/s, ζ = 1을 원해도 m = 1 kg인 링크는 k<sub>p</sub> = 100 N/m, m = 100 kg인 링크는 10,000 N/m가 든다(k<sub>p</sub> = mω<sub>n</sub>²). 같은 움직임을 원해도 이득은 질량에 비례한다. 질량이 바뀌는 팔에서는 이득도 따라 바꿔야 하는데, 이것이 다음 절의 주제다.

## 14.4 제어 분할: 단위 질량으로 설계하고 질량을 곱한다

### 문제: 팔의 질량은 바뀐다

12장에서 종이 팔 어깨의 관성 M₁₁ = 2487 + 1200 cos θ₂ g·cm²를 구했다. 편 팔(θ₂ = 0°)에서 3687, 150° 접은 팔에서 1448로 2.5배 차이가 난다. 이득을 고정해 두면 ω<sub>n</sub> ∝ 1/√m, ζ ∝ 1/√m라 자세마다 응답이 달라진다.

### 단위 질량 시스템

먼저 질량이 1인 가상의 시스템 ẍ = F′을 생각한다. 이것을 **단위 질량 시스템**(unit-mass system)이라 하고, 이 시스템의 것에는 프라임(′)을 붙인다. 이 시스템의 PD 이득은 질량이 1이라 아주 간단하다.

```latex
F' = -k_p'\,(x - x_d) - k_v'\,\dot x
```

```latex
k_p' = \omega_n^2,\qquad k_v' = 2\zeta\omega_n
```

실제 블록에는 F = m F′을 준다. 그러면 m ẍ = m F′, 곧 ẍ = F′이 되어 블록이 단위 질량 시스템처럼 움직인다. 실제 이득은 k<sub>p</sub> = m k<sub>p</sub>′, k<sub>v</sub> = m k<sub>v</sub>′다.

ω<sub>n</sub> = 10, ζ = 1이면 k<sub>p</sub>′ = 100, k<sub>v</sub>′ = 20이다. 블록이 2 kg이면 200과 40, 6 kg이면 600과 120이다. 질량을 알면 곱하는 숫자만 바꾸면 되고, 응답은 그대로다.

### 비선형 항까지: F = αF′ + β

실제 시스템에는 질량 말고도 힘이 더 있다. 레일의 마찰, 세워 든 팔의 중력, 여러 관절이면 원심력과 코리올리 힘이다. 이것을 묶어 b(x, ẋ)라 쓴다.

```latex
m\,\ddot x + b(x, \dot x) = F
```

마찰이 속도의 방향만 따르거나(**쿨롱 마찰**, Coulomb friction) 중력이 cos θ를 따르면 b는 비선형이다. 이득 하나로는 흡수할 수 없다. 대신 모델로 b를 계산해 미리 빼 준다.

```latex
F = \alpha\,F' + \beta,\qquad \alpha = \hat m,\qquad \beta = \hat b(x, \dot x)
```

모자(ˆ)는 모델로 추정한 값이라는 뜻이다. 추정이 맞으면 m ẍ + b = m F′ + b라서 ẍ = F′만 남는다. 모델이 맡는 몫(α, β)과 되먹임이 맡는 몫(F′)으로 나누어서 이것을 **제어 분할**(control partitioning)이라 한다.

### 예: 세워 든 링크

11장의 세워 든 링크(10 cm, 100 g)는 I₀θ̈ + m g l<sub>c</sub> cos θ = τ였다. 질량 자리는 I₀ = 3.33 × 10⁻⁴ kg·m², 비선형 항은 중력 0.049 cos θ N·m다. 제어 분할은 이렇게 된다.

```latex
\tau = I_0\,\tau' + 0.049\cos\theta
```

```latex
\tau' = -k_p'\,(\theta - \theta_d) - k_v'\,\dot\theta
```

β가 중력을 정확히 받쳐 주면 링크는 무게가 없는 것처럼 움직인다. β를 빼면 어떻게 되는지는 14.6절에서 본다.

## 14.5 궤적 따라가기: 가속도를 앞먹임하고 오차에 PD

지금까지는 정해진 한 점으로 가는 제어였다. 그런데 10장에서 만든 궤적은 시각마다 목표 위치 x<sub>d</sub>(t), 속도 ẋ<sub>d</sub>(t), 가속도 ẍ<sub>d</sub>(t)가 있다. 점으로 가는 PD를 그대로 쓰면 −k<sub>v</sub>′ẋ 항이 움직이는 중에도 속도를 0으로 끌어당긴다.

### 첫 생각: 가속도를 그대로 넣는다

제어 분할 덕분에 시스템은 ẍ = F′이다. 그러면 F′ = ẍ<sub>d</sub>로 두면 블록이 원하는 가속도로 움직일 것이다. 측정 없이 미리 계산해 넣는 이런 몫을 **앞먹임**(feedforward)이라 한다.

하지만 앞먹임만으로는 안 된다. 질량 추정이 조금 틀리거나 출발 위치가 어긋나면 오차가 생기고, 아무도 고치지 않아 쌓여 간다.

### 오차에 PD를 더한다

위치 오차와 속도 오차에 PD를 걸어 앞먹임에 더한다.

```latex
F' = \ddot x_d - k_v'\,(\dot x - \dot x_d) - k_p'\,(x - x_d)
```

오차를 e = x − x<sub>d</sub>라 하면 닫힌 루프는 오차의 식이 된다.

```latex
\ddot e + k_v'\,\dot e + k_p'\,e = 0
```

> **수학 더하기: 오차로 옮겨 적기.** e = x − x<sub>d</sub>를 시간으로 미분하면 ė = ẋ − ẋ<sub>d</sub>, ë = ẍ − ẍ<sub>d</sub>다. ẍ = F′에 위의 F′을 넣고 ẍ<sub>d</sub>를 왼쪽으로 옮기면 ẍ − ẍ<sub>d</sub> = ë가 된다. 나머지 두 괄호는 ė와 e다.

오차가 14.2절의 계단 응답과 같은 2차 식을 따라 0으로 간다. 그래서 k<sub>p</sub>′ = ω<sub>n</sub>², k<sub>v</sub>′ = 2ω<sub>n</sub>(ζ = 1)으로 고르면 오차가 넘치지 않고 줄어든다.

## 14.6 외란과 정상 상태 오차

모델은 늘 조금씩 틀린다. 질량과 중력 추정의 오차, 기어의 마찰, 사람이 미는 손이 있다. 모델에 없는 힘을 모두 묶어 **외란**(disturbance) F<sub>d</sub>라 한다.

```latex
m\,\ddot x + b(x, \dot x) = F + F_d
```

F = m F′ + b로 나머지는 정확히 뺐다고 하자. 그러면 오차의 식에 외란이 남는다.

```latex
\ddot e + k_v'\,\dot e + k_p'\,e = \frac{F_d}{m}
```

외란은 실제 시스템에 들어오는 힘이라서, 단위 질량 쪽으로 옮기면 m으로 나뉜다.

### 다 가라앉은 뒤의 오차

F<sub>d</sub>가 일정하면 결국 움직임이 멈춘다(ë = ė = 0). 그때 남는 오차를 **정상 상태 오차**(steady-state error)라 한다.

```latex
e_{ss} = \frac{F_d}{m\,k_p'} = \frac{F_d}{k_p}
```

용수철에 추를 매달면 무게 ÷ 용수철 상수만큼 늘어나는 것과 같다. 블록(m = 2 kg, k<sub>p</sub>′ = 100)이면 k<sub>p</sub> = 200 N/m다. 2 N으로 밀면 2 / 200 = 0.01 m, 1 cm 밀린 채로 멈춘다.

### 단단함은 k<sub>p</sub>′가 아니라 m k<sub>p</sub>′

닫힌 루프의 **단단함**(closed-loop stiffness)은 1 m 밀렸을 때 되미는 힘, 곧 k<sub>p</sub> = m k<sub>p</sub>′다. 제어 분할로 ω<sub>n</sub>은 일정하게 지켰지만 단단함은 질량을 따라 바뀐다.

종이 팔이라면 접은 팔(M₁₁ = 1448)이 편 팔(3687)보다 2.5배 무르다. 같은 힘으로 밀어도 접은 자세에서 2.5배 더 밀린다. 그래서 k<sub>p</sub>′는 가장 가벼운 자세에서도 오차가 허용 범위에 들도록 크게 잡는다.

> **알아 두기.** 강의는 어떤 교재가 외란을 m으로 나누지 않고 단위 질량 시스템에 바로 더해 쓴다고 짚는다. 그렇게 쓰면 오차가 k<sub>p</sub>′에 반비례하는 것처럼 보인다. 외란은 실제 힘이므로, 오차는 k<sub>p</sub>′가 아니라 m k<sub>p</sub>′에 반비례한다.

### 중력이 외란일 때: 세워 든 링크

세워 든 링크에서 β(중력 보상)를 빼고 τ = I₀τ′만 준다. 그러면 중력이 모델에 없는 외란이 된다. 링크는 PD의 용수철 토크가 중력 토크와 맞서는 자리에서 멈춘다.

```latex
k_p\,(\theta_d - \theta) = m g\,l_c \cos\theta
```

처짐이 작으면 오른쪽의 θ를 θ<sub>d</sub>로 바꿔 θ<sub>d</sub> − θ ≈ G(θ<sub>d</sub>) / k<sub>p</sub>로 어림한다. ω = 20 rad/s이면 k<sub>p</sub> = I₀ω² = 0.133 N·m/rad다.

수평(θ<sub>d</sub> = 0°)을 지키려 하면 0.049 / 0.133 = 0.37 rad, 약 21° 처진다고 어림된다. 실제로 풀면 19.8°다. 링크가 처지면 cos θ가 조금 줄어서 어림보다 덜 처진다.

## 14.7 PID: 적분 항이 남은 오차를 지운다

PD는 F<sub>d</sub> / k<sub>p</sub>만큼 오차를 남긴다. k<sub>p</sub>를 올리면 줄지만 14.3절의 한계가 있다. 다른 길은 오차를 시간에 걸쳐 쌓는 **적분 항**(integral term)을 더하는 것이다.

```latex
F' = \ddot x_d - k_v'\,\dot e - k_p'\,e - k_i' \int_0^t e\,dt
```

비례(P), 적분(I), 미분(D) 세 몫이라 **PID 제어**라 한다. k<sub>i</sub>′는 **적분 이득**(integral gain)이다.

> **수학 더하기: 적분은 쌓인 넓이.** ∫₀ᵗ e dt는 0초부터 지금까지 e(t) 그래프 아래의 넓이다. e가 1 cm로 0.5초 이어지면 0.5 cm·s가 쌓인다. 오차가 남아 있는 한 넓이는 계속 커지고, 오차가 0이 되어야 커지기를 멈춘다.

### 왜 오차가 0이 되나

닫힌 루프 식에 적분이 하나 더 붙는다.

```latex
\ddot e + k_v'\,\dot e + k_p'\,e + k_i' \int_0^t e\,dt = \frac{F_d}{m}
```

양변을 시간으로 한 번 미분한다. 적분을 미분하면 원래의 e로 돌아오고, F<sub>d</sub>가 일정하면 오른쪽은 0이 된다.

```latex
\frac{d^3 e}{dt^3} + k_v'\,\ddot e + k_p'\,\dot e + k_i'\,e = 0
```

다 가라앉으면 e의 미분은 모두 0이라 k<sub>i</sub>′e = 0, 곧 e = 0이다. 외란을 받치는 힘은 적분 항이 쌓아 둔 값이 댄다.

@fig fig14_7 | 적분 항은 남은 오차가 0이 될 때까지 힘을 쌓는다 | 그림 14-7 · 직접 바꿔 보기: 일정한 외란과 적분 이득 | 블록(2 kg)이 x<sub>d</sub> = 0을 지키다가 0.5초부터 일정한 힘 F<sub>d</sub>를 받는다. 이득은 k<sub>p</sub>′ = 100, k<sub>v</sub>′ = 20(ω<sub>n</sub> = 10 rad/s, ζ = 1)이다.

해 볼 것 네 가지:

1. k<sub>i</sub>′ = 0: 1 cm 밀린 채 멈춘다. 14.6절의 F<sub>d</sub> / k<sub>p</sub> = 2/200 m다.
2. k<sub>i</sub>′ = 300: 0.71 cm까지 밀렸다가 2초 무렵에는 거의 0으로 돌아온다.
3. k<sub>i</sub>′ = 1000: 0.55 cm로 덜 밀리지만 출렁이며 돌아온다.
4. k<sub>i</sub>′를 2000 넘게 올린다. 출렁임이 줄지 않고 커진다.

4번의 경계는 3차 식이 안정할 조건에서 나온다. 아래 꼴의 식은 a, b, c가 모두 양수이고 ab > c일 때 오차가 0으로 간다(증명은 제어 과목에서 배운다).

```latex
\frac{d^3 e}{dt^3} + a\,\ddot e + b\,\dot e + c\,e = 0
```

여기서는 a = k<sub>v</sub>′ = 20, b = k<sub>p</sub>′ = 100, c = k<sub>i</sub>′라서 k<sub>i</sub>′ < 2000이어야 한다.

### 적분 누적을 조심한다

적분 항에는 함정이 있다. 크게 빨리 움직이는 동안이나 모터가 포화된 동안에도 오차가 쌓인다.

목표에 닿을 즈음에는 적분 값이 너무 커져 있어서, 그것을 다 풀어낼 때까지 목표를 지나친다. 이것을 **적분 누적**(integral windup)이라 한다.

그래서 적분은 목표 근처에서만 켜거나, 쌓이는 값에 상한을 두거나, 포화된 동안에는 멈춘다. 강의는 운동 제어에서는 적분을 조심해서 쓰고, 힘 제어(16장)에서 쓸모가 크다고 말한다.

처짐은 결국 사라진다. 하지만 적분이 쌓이는 동안은 처져 있고, 목표 각이 바뀌면 중력 토크도 바뀌어 다시 쌓아야 한다. 모델로 아는 몫은 β로 바로 빼고, 모델이 놓친 작은 나머지를 적분이 맡는 것이 좋다.

## 14.8 기어비와 유효 관성

이제 관절 속을 들여다본다. 모터는 링크를 직접 돌리지 않고, 기어를 거쳐 돌린다.

@fig fig14_8 | 기어는 빠르기를 토크로 바꾸고 회전자를 η²배 무겁게 보이게 한다 | 그림 14-8 · 모터, 기어, 링크 | 모터에 붙은 작은 기어(반지름 r)가 링크에 붙은 큰 기어(반지름 R)를 돌린다.

**기어비**(gear ratio)는 η = R / r이다. 링크가 한 바퀴 돌 때 모터는 η바퀴 돈다.

- 빠르기: θ̇<sub>m</sub> = η θ̇<sub>L</sub>. 모터가 η배 빨리 돈다.
- 토크: τ<sub>L</sub> = η τ<sub>m</sub>. 링크에서는 모터 토크의 η배가 나온다. 일률 τθ̇이 기어를 지나도 같기 때문이다(마찰을 무시하면).

기어를 쓰는 까닭은 작고 가벼운 모터로 큰 토크를 내기 위해서다. η = 1인 **직접 구동**(direct drive)은 큰 토크를 내려면 크고 무거운 모터가 필요하고, 그 무게를 안쪽 관절이 들어야 한다. PUMA의 기어비는 50~150이고, 여러 단을 겹쳐 300에 이르는 로봇도 있다.

> **잠깐, 생각해 보기.** 모터 회전자의 관성 I<sub>m</sub>은 링크에서 보면 얼마로 보일까? 토크처럼 η배일까?

η²배로, η가 두 번 들어간다. 링크를 θ̈<sub>L</sub>로 가속하면 회전자는 η배인 ηθ̈<sub>L</sub>로 가속해야 하고, 이것이 한 번이다. 회전자를 가속하는 데 든 토크는 기어를 지나 링크에서 η배로 보이고, 이것이 또 한 번이다.

### 식으로 확인하기

기어가 회전자에 거는 토크를 τ<sub>c</sub>라 하자. 모터 쪽과 링크 쪽의 운동 방정식은 각각 다음과 같다.

```latex
\tau_m - \tau_c = I_m\,\ddot\theta_m,\qquad \eta\,\tau_c = I_L\,\ddot\theta_L
```

θ̈<sub>m</sub> = ηθ̈<sub>L</sub>을 넣고 τ<sub>c</sub>를 지운 다음, 양변에 η를 곱한다.

```latex
\eta\,\tau_m = \left(I_L + \eta^2 I_m\right)\ddot\theta_L
```

링크 쪽에서 본 관성 I<sub>eff</sub> = I<sub>L</sub> + η²I<sub>m</sub>을 **유효 관성**(effective inertia)이라 한다. 같은 까닭으로 모터의 마찰도 b<sub>eff</sub> = b<sub>L</sub> + η²b<sub>m</sub>으로 η²배가 된다.

### 숫자로 보기

작은 모터의 회전자 관성을 I<sub>m</sub> = 0.5 g·cm²라 하자(예시 값). 회전자 자체는 아주 가볍다. 그런데 η = 100이면 η²I<sub>m</sub> = 10,000 × 0.5 = 5000 g·cm²로, 편 종이 팔 전체의 M₁₁ = 3687보다 크다.

토크와 빠르기도 계산해 보자. 세워 든 링크를 수평으로 버티는 0.049 N·m를 η = 100으로 내면 모터는 0.00049 N·m면 된다. 대신 링크가 2 rad/s로 돌 때 모터는 200 rad/s(약 1900 rpm)로 돈다.

> **알아 두기.** 유효 관성이 크면 위험하다. 팔이 무엇에 부딪히면 링크만이 아니라 η²배로 커 보이는 회전자까지 한꺼번에 멈춰야 해서 충격이 커진다. 그래서 사람 곁에서 일하는 로봇은 기어비를 줄이거나 다른 방법을 쓴다(16장). 중력을 들 필요가 없는 수평 팔(SCARA)은 직접 구동을 쓰기도 한다.

## 14.9 기어가 크면 관절이 따로 논다

12장의 종이 팔에서 어깨의 M₁₁은 자세에 따라 1448에서 3687 g·cm²로 바뀌었다. 게다가 얽힘 칸 M₁₂ = 320 + 600 cos θ₂가 팔꿈치의 움직임을 어깨에 전한다(편 팔에서 920).

기어는 이 그림을 바꾼다. 모터 몫 η²I<sub>m</sub>은 자기 관절의 대각 칸에만 더해지고, 자세와 상관없이 일정하다. 얽힘 칸 M₁₂는 그대로다.

@fig fig14_9 | 기어비가 클수록 자세가 바뀌어도 관절의 무게감이 거의 같다 | 그림 14-9 · 직접 바꿔 보기: 종이 팔 어깨의 유효 관성 | 12장의 종이 팔(손에 든 물건 없음) 어깨 관성 M₁₁에 모터 몫 η²I<sub>m</sub>(I<sub>m</sub> = 0.5 g·cm²)을 더했다. 막대 길이는 편 팔의 I<sub>eff</sub>에 맞춰 줄였다.

해 볼 것 세 가지:

1. η = 1(직접 구동): 무거울 때와 가벼울 때가 2.55배 차이 난다. 얽힘 비율 M₁₂ ÷ I<sub>eff</sub>는 25%다.
2. η = 100: I<sub>eff</sub>가 6448 ~ 8687로 1.35배 차이뿐이다. 얽힘 비율은 11%로 준다.
3. η = 300: 1.05배다. 자세가 어떻든 관절의 무게감이 거의 같다.

기어비가 크면 관절마다 관성이 거의 일정하고, 다른 관절이 거는 얽힘 토크는 큰 관성에 비해 작아진다. 그 얽힘은 작은 외란으로 보고 단단한 PD가 막는다(14.6절). 그래서 관절마다 고정 이득의 PD를 따로 다는 **독립 관절 제어**(independent joint control)가 잘 통한다. 강의의 PUMA 시뮬레이터에서 "동역학 없는 관절 제어"로 바꿔 돌린 것이 이 방식이다.

### 고정 이득은 어디에 맞추나

유효 관성이 I<sub>min</sub>과 I<sub>max</sub> 사이에서 바뀔 때, 강의는 두 값의 기하 평균 √(I<sub>min</sub> I<sub>max</sub>)에 이득을 맞추라고 한다. 그러면 ω<sub>n</sub>이 위아래로 같은 비율 (I<sub>max</sub> / I<sub>min</sub>)<sup>1/4</sup>만큼만 벗어난다.

예를 들어 기하 평균에서 ω<sub>n</sub> = 20 rad/s, ζ = 1로 맞춘다. 직접 구동이면 ω<sub>n</sub>이 15.8 ~ 25.3 rad/s로 퍼지고, 가장 무거울 때 ζ = 0.79가 되어 1.7% 넘친다. η = 100이면 18.6 ~ 21.5 rad/s, ζ ≥ 0.93이다.

> **알아 두기.** 큰 기어에는 대가가 있다. 마찰과 충돌 때의 무게감이 η²배로 커지고, 기어 이 사이의 틈(백래시)과 휨이 공진 진동수를 낮춰 14.3절의 ω 한계를 끌어내린다. 그래서 빠르고 정밀한 팔일수록 기어를 줄이고, 15장의 모델 기반 제어로 얽힘을 직접 푼다.

이것으로 14강 내용이 끝난다. 다음 15강에서는 이 장의 제어 분할을 여러 관절의 팔 전체로 넓히고, 손끝을 작업 공간에서 직접 제어한다.

### 파이썬으로 확인

파이썬(numpy)이 있으면 아래를 붙여 넣어 돌려 본다. 시뮬레이션은 2 ms 간격의 룽게-쿠타 4단(그림들과 같은 방법)이다. 주석의 값이 그대로 나온다.

```python
import numpy as np

def R(v, n=2):
    return round(float(v), n) + 0.0          # 보기 좋게 반올림 (−0.0은 0.0으로)

def pd_info(m, kp, kv):
    """닫힌 루프 ω_n, ζ, 넘침(%), 첫 봉우리 시각 t_p."""
    w, z = np.sqrt(kp / m), kv / (2 * np.sqrt(m * kp))
    if z >= 1:
        return R(w), R(z), 0.0, None
    over = np.exp(-np.pi * z / np.sqrt(1 - z * z)) * 100
    return R(w), R(z), R(over, 1), R(np.pi / (w * np.sqrt(1 - z * z)), 3)

def rk4(f, s0, T, dt=0.002):
    """고정 간격 룽게-쿠타 4단. 칸 경계에서 바뀌는 힘을 정확히 넣으려고
    첫 단계는 칸의 바로 오른쪽, 끝 단계는 바로 왼쪽에서 잰다."""
    s, out = np.array(s0, float), []
    for i in range(round(T / dt)):
        t = i * dt
        k1 = f(t + 1e-9, s)
        k2 = f(t + dt / 2, s + dt / 2 * k1)
        k3 = f(t + dt / 2, s + dt / 2 * k2)
        k4 = f(t + dt - 1e-9, s + dt * k3)
        s = s + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
        out.append((t + dt, s.copy()))
    return out

def step(m, kp, kv, goal=10, T=4):
    """0 → 10 cm 계단 응답의 넘침(%)과 정착 시간(2%)."""
    f = lambda t, s: np.array([s[1], (-kp * (s[0] - goal) - kv * s[1]) / m])
    run = rk4(f, [0, 0], T)
    x = np.array([s[0] for t, s in run])
    tt = np.array([t for t, s in run])
    out = np.where(abs(x - goal) > 0.02 * goal)[0]
    return R((x.max() - goal) / goal * 100, 1), R(tt[out[-1]])

# 14.5 궤적 따라가기: ω = 10, 추정 질량 = 0.8 × 실제 질량
def traj(t):
    if t < 0: return 0, 0, 0
    if t > 1: return 10, 0, 0
    return 10 * (3*t**2 - 2*t**3), 10 * (6*t - 6*t**2), 10 * (6 - 12*t)

def track(mode, w=10, r=0.8):
    kp, kv = w * w, 2 * w
    def f(t, s):
        p, pd, pdd = traj(t)
        if mode == 'pd':
            Fp = -kv * s[1] - kp * (s[0] - p)
        elif mode == 'ff':
            Fp = pdd
        else:
            Fp = pdd - kv * (s[1] - pd) - kp * (s[0] - p)
        return np.array([s[1], r * Fp])       # m ẍ = (추정 질량) F′
    run = rk4(f, [0, 0], 1.6)
    err = max(abs(s[0] - traj(t)[0]) for t, s in run)
    return R(err), R(run[-1][1][0])            # 가장 큰 오차, 1.6초의 위치 (cm)

print([track(m) for m in ['pd', 'ff', 'ff+pd']])
```
