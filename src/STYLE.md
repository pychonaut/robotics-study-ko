# 교재 원고 규칙 (장을 새로 쓰는 사람용)

이 파일은 빌드되지 않는다. 새 장을 쓰기 전에 끝까지 읽고, `src/ch1.md`, `src/ch2.md`, `docs/assets/figures.js`를 먼저 읽어 말투와 그림 모양을 맞춘다.

## 무엇을 만드나

- 독자: 고등학교 수학(삼각함수)을 아는 한국어 독학자. 행렬·미분은 처음일 수 있다. 처음 나오는 수학은 "수학 더하기" 상자로 그 자리에서 설명한다.
- 강의 1개 = 장 1개. 강의를 보기 전에 읽는 **교재**다. 요약집이 아니다. 개념마다 왜 필요한지 → 그림 → 설명 → 직접 해 보기 순서로 차근차근 쌓는다.
- 강의 전사본은 내용과 순서를 파악하는 데만 쓴다. **전사본을 번역하거나 길게 옮기지 않는다.** 설명, 예제 숫자, 문제, 그림은 새로 만든다. 강의의 예제를 쓸 때는 "강의 예제"라고 밝히고 짧게 다시 설명한다.
- 강의에서 빠르게 지나간 부분은 교재가 풀어서 채운다. 표준 로봇공학 내용(Craig 교재 수준)으로 보충해도 된다. 틀린 내용이 없게 숫자는 직접 계산해 확인한다.

## 원고 파일 형식 (`src/chN.md`)

```
# N장. 제목
<!-- card: 강의 N강 · 목차 카드에 들어갈 한 줄 -->

<p class="lead">이 장에서 얻는 것 2~3문장. 강의 N강(MM분)에 해당한다.</p>

## N.1 소제목
...
## N.k 연습문제
### 답
### 파이썬으로 확인
### 스탠퍼드 숙제
```

- 절은 6~11개. 절 번호는 `N.1`부터.
- 마지막 절은 연습문제(5~8문제) → `### 답`(풀이 과정까지) → `### 파이썬으로 확인`(numpy 코드, 주석에 실제 출력값) → `### 스탠퍼드 숙제`(해당 숙제 번호만 안내, 문제는 옮기지 않는다).
- 장 아래의 이전·다음 이동 링크는 빌드가 붙인다. 원고에 쓰지 않는다.

### 말투

- 문장은 "~다"로 끝낸다. 한 문장 25단어 안, 한 문단 3문장 안.
- 쉬운 말을 쓴다. 용어는 처음 나올 때 `**한국어 용어**(English)`로 쓴다.
- **굵게 규칙**: 닫는 `**` 바로 앞이 괄호·따옴표 같은 문장부호이고 바로 뒤가 한글이면 굵게가 깨진다. `**자유도**(degree of freedom)가`처럼 괄호를 굵게 밖으로 뺀다. `**"원점"**이다` 대신 `"**원점**"이다`로 쓴다.
- 아래첨자는 본문에서 `x<sub>B</sub>`처럼 쓴다. θ₁, m₀ 같은 유니코드 아래첨자 숫자는 그대로 써도 된다.
- 본문 속 짧은 식은 유니코드 글자로 쓴다(예: θ₁ + θ₂, ẋ = J θ̇). 줄을 따로 차지하는 식은 아래 latex 블록으로 쓴다.

### 상자 세 가지 (인용문 `>`으로 쓴다)

- `> **잠깐, 생각해 보기.** 질문` → 바로 다음 문단에 답을 쓴다. 장마다 3~6개.
- `> **수학 더하기: 주제.** 설명` → 그 자리에서 필요한 수학(미분, 외적, 편미분 등)을 짧게 가르친다.
- `> **알아 두기.** 내용` → 실제 로봇에서 생기는 일, 흔한 실수.

### 수식

````
```latex
{}^{A}_{B}R = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}
```
````

- KaTeX가 그린다. `\text{...}` 안에는 중괄호를 쓰지 않는다. 한 줄 식이 너무 길면(폰 화면) 두 블록으로 나눈다.
- 좌표계 표기는 2장과 같다: `{}^{A}_{B}R`, `{}^{A}P`, `{}^{A}_{B}T`, `{}^{A}P_{B\,org}`.

### 영상 링크

절 끝마다 `영상에서 보기: [mm:ss 설명](https://youtu.be/<영상ID>?t=<초>)`를 1~4개 단다. 시각은 `~/media.noindex/paper-ai/CS223A_자막/텍스트/강의NN_유튜브자막.txt`의 `[mm:ss]`에서 찾는다(전사본에는 시각이 없다). 초는 정확히 계산한다(예: 12:34 → t=754).

## 이 교재 전체에서 같이 쓰는 것

- **종이 팔**: 책상 위에서 평면으로 움직이는 2관절 팔. 링크 1 = 10 cm, 링크 2 = 8 cm, 어깨 각 θ₁, 팔꿈치 각 θ₂(링크 1을 늘인 선에서 잰다). 받침 좌표계 {0}. 손끝 x = 10 cos θ₁ + 8 cos(θ₁+θ₂), y = 10 sin θ₁ + 8 sin(θ₁+θ₂). 새 개념은 가능하면 이 팔로 먼저 보이고, 그다음 강의의 3차원 팔(스탠퍼드 Scheinman 팔, PUMA 등)로 넓힌다.
- 2장의 카메라 예: 받침에서 (10, 5) cm, 방향 θ. 필요하면 다시 쓴다.
- 3관절 팔이 필요하면 8 cm, 7 cm, 5 cm(2장 2.3절과 같음).
- 3차원 예가 필요하면 7장의 "돌림판 종이 팔"(받침 회전 + 어깨 + 팔꿈치, 링크 10 cm·8 cm).
- 용어: 손목의 세 축이 만나는 점은 "손목 중심"(5장). 손끝이 닿을 수 있는 영역은 "닿는 영역"(workspace), 손끝 좌표의 공간은 "작업 공간"(operational space).
- 개인 프로젝트나 특정 부품 계획(무슨 단계에서 무엇을 만든다 등)은 쓰지 않는다. "서보(작은 모터)", "모터" 같은 일반 표현은 괜찮다.

## 그림

장마다 그림 5~9개, 그중 **슬라이더로 움직이는 그림 2개 이상**. 강의 칠판 그림을 베끼지 말고 새로 그린다. 그림은 개념을 한눈에 보이게 하는 데 쓴다(관계, 화살표, 전후 비교). 글만 늘어놓은 상자 그림은 피한다.

### 원고에 그림 넣기

```
@fig fig5_2 | 그림 위 제목 (그림이 말하는 결론 한 문장) | 그림 5-2 · 캡션 | 그림 아래 설명(없어도 됨)
```

### 그림 코드 (`docs/assets/figs/chN.js`)

```js
(function () {
  const { D, f1, f2, svg, T, L, A, AA, C, joint, link, arc, annulus, interactive, sub, matrix2 } = FigKit;
  const FIG = window.FIG;

  FIG.fig5_1 = el => {                       // 정적 그림
    const id = 'f51';                         // 화살표 표식 이름. 그림마다 다르게
    el.innerHTML += svg(id, [y0, h], [ ... ].join(''), '화면낭독기용 설명');
  };

  FIG.fig5_2 = el => interactive(el, {      // 슬라이더 그림
    state: { t1: 50 },
    sliders: [{ key: 't1', label: '어깨 θ₁', min: -180, max: 180, step: 1, unit: '°' }],
    draw: s => svg('f52', [y0, h], [ ... ].join(''), '설명'),
    readout: s => `<b>손끝</b> = (${f1(x)}, ${f1(y)}) cm`,   // 그림 아래 숫자 (HTML)
  });
})();
```

도구(`docs/assets/figures.js` 안에 있다):

| 이름 | 하는 일 |
| --- | --- |
| `svg(id, [y0, h], body, label)` | 폭 480, 세로 y0~y0+h를 보여 주는 SVG. 화살표 표식 `#id-axis`, `#id-ink`, `#id-c1`, `#id-c2` 포함 |
| `T(x, y, 글자, {a, c, s})` | 글자. a = 'start'·'middle'·'end', c = 'q'(흐림)·'b'(굵게)·'q b', s = 크기(기본 14) |
| `L(x1, y1, x2, y2, 색, 굵기, 그밖)` | 선. 색 = 'axis'(회색)·'grid'(옅은 회색)·'ink'(검정)·'c1'(파랑)·'c2'(주황). 그밖에 `A(id,'c1')`(끝 화살표), `AA(id,'c1')`(양끝), `'stroke-dasharray="4 4"'` |
| `C(x, y, r, 'f-c1 s-axis', 굵기)` | 원. 채움 f-axis·f-ink·f-c1·f-c2·f-tint·f-none, 테두리 s-… |
| `joint(x, y, r)` · `link(x1, y1, x2, y2, 색, 두께)` | 관절 원, 두꺼운 링크 |
| `arc(ox, oy, r, 시작각, 끝각, 색, 굵기, 그밖)` | 각도 호(라디안, 수학 방향) |
| `annulus(cx, cy, R, r)` | 손끝이 닿는 고리 영역 |
| `sub('x', 'B')` | SVG 글자 속 아래첨자 |
| `matrix2(a, b, c, d)` | readout 안의 2×2 행렬 표 |
| `D`, `f1`, `f2` | 도→라디안, 소수 1·2자리 |

- SVG 글자에 색을 주려면 `T(..., {c: 'f-c1'})`처럼 f-c1·f-c2 클래스를 쓴다.
- 사각형·다각형·경로는 직접 `<rect ... class="f-tint s-axis" stroke-width="1.25"/>`처럼 쓴다. 색은 반드시 class로(밝은/어두운 화면 자동 전환). hex 색을 쓰지 않는다.
- 좌표는 SVG 방향(y가 아래로 커짐)이다. 수학 좌표 (x, y)는 `[ox + s*x, oy - s*y]`로 바꾼다.
- 글자가 선이나 다른 글자와 겹치지 않게 자리를 잡는다. 한글 14px 글자 하나 ≈ 14 단위 폭. 폭 480을 넘지 않는다.
- 그림 위 제목·아래 설명은 원고의 `@fig` 줄에 쓴다(SVG 안에 넣지 않는다). SVG 안에는 축 이름, 점 이름, 짧은 표시만.
- 폰에서는 그림이 약 0.7배로 줄어든다. SVG 글자는 12.5 이상.
