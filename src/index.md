# 종이 팔로 배우는 로봇공학 입문

<p class="lead">스탠퍼드 대학 CS223A 「로봇공학 입문」(Oussama Khatib 교수, 2008년, 16강)을 혼자 공부하려고 한국어로 새로 쓴 교재다. 책상 위 종이 팔 하나를 예로 들어, 그림과 직접 움직여 보는 그림으로 설명한다.</p>

3장(강의 3강)부터는 이어서 쓰는 중이다.

## 이 교재로 공부하는 법

1. 장을 먼저 읽는다. 슬라이더가 있는 그림은 직접 움직여 본다.
2. 절마다 있는 "영상에서 보기" 링크로 강의의 그 장면을 본다. 강의는 영어이고 유튜브에서 영어 자막을 켤 수 있다.
3. "잠깐, 생각해 보기"에서 멈추고 답을 적어 본다.
4. 장 끝 문제를 손으로 푼다.
